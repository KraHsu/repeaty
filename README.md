# repeaty

专注卡片与间隔复习的本地学习空间。Vue 3 + TypeScript + Vite，当前版本 **0.3.0**。

## 开发与验证

需要 Node.js 24.12+（建议 Node.js 24 LTS）。

```bash
npm ci
npm run dev
```

默认开发地址为 `http://127.0.0.1:5173`。首次使用为空空间，可创建卡组或加载入门示例。

```bash
npm run format:check # 格式检查；npm run format 自动整理
npm run typecheck    # Vue / TypeScript 类型检查
npm test             # 核心逻辑、离线缓存、语言偏好与 DOM 交互测试
npm run build        # 类型检查与生产构建，输出到 dist/
npm run preview      # 本地预览生产构建
npm run test:e2e     # 构建后执行 Playwright，使用生产站点而非开发服务器
npm run check        # 格式检查 + 单元测试 + 构建 + 浏览器测试
```

首次运行浏览器测试先执行 `npx playwright install chromium`。也可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome` 使用已有 Chrome。浏览器测试启动 `127.0.0.1:4175`，覆盖制卡、复习、撤销、额度、批量管理、媒体恢复、快捷制卡、常用筛选、两种专项练习、自动暂缓、双语切换与偏好持久化、移动端布局和断网重载。

完整检查包含 Chromium 浏览器测试。若本机沙箱拒绝监听 / 访问预览端口（`EPERM`），请在允许本机端口的终端运行。单元测试包含 Service Worker 生命周期、离线响应和失败更新回退，不能替代真实浏览器断网验证。

## 界面语言

顶部语言选择器支持 **English / 中文（简体）**。首次打开按浏览器语言偏好选择，识别英语和中文的地区变体；没有匹配语言时使用 English。手动选择保存在当前网站的 `localStorage`（`repeaty.locale`），刷新后沿用；存储不可用时仍可在本次会话切换。

导航、编辑表单、复习评分、搜索提示、通知、校验错误、日期、间隔和快照原因随界面语言变化，无需刷新。切换不改动卡片内容、卡组名称、标签、常用筛选、复习进度或已有快照，也不会结束当前复习。语言偏好独立于学习数据，不包含在 JSON 备份中。入门示例在添加时使用当前语言；CSV 示例与 PWA 安装信息也提供两种语言，并随应用离线缓存。

文案集中在 `src/i18n/en.ts`，使用中文源文案作为稳定键；`t()` 负责响应式显示，带参数的通知与错误通过 `msg()` / `LocalizedError` 保留原始信息，避免切换语言后仍显示旧语言。用户内容作为参数插入，不参与翻译。已持久化的中文筛选状态和快照原因只翻译显示，不修改存储格式。

## 笔记与卡片

一条笔记保存内容、标签、媒体和所属卡组，并生成一张或多张卡片。各张卡片分别保存 FSRS 进度、暂停和暂缓状态。

| 笔记类型        | 生成规则                                           |
| --------------- | -------------------------------------------------- |
| 正反面 `basic`  | 一张正面 → 背面卡片                                |
| 双向 `reversed` | 正面 → 背面、背面 → 正面两张卡片，媒体也随两面交换 |
| 挖空 `cloze`    | 每个不同挖空编号生成一张卡片，相同编号一起隐藏     |

挖空示例：

```text
法国的首都是 {{c1::巴黎::城市}}，日本的首都是 {{c2::东京}}。
```

支持 `{{c1::答案}}` 与 `{{c1::答案::提示}}`，编号 1–99；当前不支持嵌套挖空。挖空笔记的背面可留空，或填写额外解释。旧笔记保持纯文本显示；新笔记可选择 Markdown / 数学公式，编辑与复习共用同一渲染器，不执行原始 HTML。

编辑笔记时，仍然存在的卡片保留原 ID、复习进度及暂停状态；新增方向 / 挖空编号生成新卡片。移除某个方向或挖空编号会删除对应卡片和记录，编辑器会要求确认，并在保存前创建快照。删除笔记会删除其所有关联卡片。

旧版 v1 / v2 数据库、JSON 备份和快照自动迁移为 v3：原卡片 ID、内容、调度状态和复习记录保留，每张旧卡转换为一条基础笔记。数据库迁移与升级前快照在同一事务中完成。v1 记录没有评分前状态，无法撤销；首次学习以外、无法判断属于复习还是学习步骤的旧记录保留为 legacy，不计入新版每日复习额度。数据库升级被旧页面阻挡时，会提示关闭旧标签页。数据库版本也升级到 3，旧页面不能继续以旧格式写入。v2 的评分撤销状态和媒体保留，新字段补默认值。

## 每日学习与复习控制

- 每个卡组可设置每日新卡与到期复习上限，默认分别为 **20 / 200 张**，0 表示不引入该类卡片。
- 额度按本机日历日重置。新卡按首次学习的卡片数扣减，正式复习按当天进入复习的不同卡片数扣减；学习 / 重学步骤继续完成，不受这两项额度限制。
- 优先顺序为到期学习 / 重学、到期复习、新卡。四档评分由 `ts-fsrs` 计算下次时间，按所属卡组的目标记忆保留率调度（默认 90%，可设 70%–97%），关闭随机间隔扰动。预览与实际评分使用同一设置；调整设置只影响之后的评分，不立刻重排已有卡片。
- 「撤销上次评分」恢复评分前调度状态、移除该次记录，并重新计算额度；连续撤销可逐步回退，重新打开页面后仍有效。不会回退笔记内容修改或暂停操作。
- 「暂停此卡」持续生效直到手动恢复；「今天暂缓」在本机日历进入下一天后自动解除。两者都不改变记忆进度。
- 卡片列表可批量暂停、恢复、暂缓或取消暂缓。统计展示实际复习次数，首页待学数量已经应用额度。
- 默认评分后自动暂缓同一笔记的其他可用卡片至明天，卡组设置中可关闭。撤销评分会撤回该评分造成的自动暂缓；手动暂停 / 暂缓不受影响，也可在列表中取消自动暂缓。
- 正式复习遗忘达到卡组阈值后自动标记「顽固卡」，默认 8 次，0 关闭。新卡初学失败不计入这个阈值。可用 `is:leech` 筛选，或批量清除标记；不会自动暂停。清除后再次正式遗忘、仍超过阈值时会重新标记。
- 复习页支持空格翻面、1–4 评分、Esc 结束。输入框和按钮保留原生键盘行为。

## 快捷制卡与内容格式

- 新笔记默认使用 Markdown，支持加粗、列表、引用、表格、代码块、链接以及 `$行内公式$` / `$$独立公式$$`。公式由本地打包的 KaTeX 渲染，字体包含在离线缓存中；不加载 CDN。需要显示原始标记时可切换为纯文本。
- 在正面选中文字，点击「选中文字挖空」或按 `Ctrl / ⌘ + Shift + C`，自动切换挖空类型并使用最小未占用编号。可挖空包含平衡 LaTeX 花括号的公式，不支持嵌套挖空。
- 可将剪贴板中的图片直接粘贴到问题 / 答案输入框，作为对应面的本地附件；继续沿用每面 8 个、每个 10 MB 限制。
- 「保存并继续」成功后清空本条内容与附件，保留卡组、题型、格式和标签。新增笔记时 `Ctrl / ⌘ + Enter` 保存并继续，编辑已有笔记时保存关闭。保存失败时保留输入。
- 展开生成预览可同时查看实际题面、答案、公式和附件。Markdown 中的外部图片仅显示占位文字，请通过附件保存图片；原始 HTML、危险链接和可信 TeX 扩展禁用。

## 高级搜索与专项练习

卡片列表支持以下搜索条件，可以用空格组合（AND），用 `-` 排除，用双引号包围含空格的值或短语。标签与卡组名按完整名称匹配，忽略大小写。

| 示例                                 | 含义                                       |
| ------------------------------------ | ------------------------------------------ |
| `tag:英语 -is:suspended`             | 英语标签，排除暂停卡片                     |
| `deck:"Study notes" "active recall"` | 指定卡组中的关键词短语                     |
| `type:cloze is:new`                  | 新的挖空卡                                 |
| `is:leech lapses:>=3`                | 顽固卡且正式遗忘至少 3 次                  |
| `due:<=7`                            | 7 个本机日历日以内到期，包括已经逾期的卡片 |
| `due:<0`                             | 到期日期早于今天                           |

`is` 支持 `new / due / review / learning / suspended / buried / leech`。`due` 和 `lapses` 支持 `= / < / <= / > / >=`，省略运算符表示相等。`is:due` 按实际到期时刻判断，不扣除额度或排除暂停；搜索结果可结合状态筛选进一步缩小范围。无效条件会显示错误。

展开「高级搜索、常用筛选与专项练习」可保存、更新、删除常用筛选，最多 100 个。保存的是条件，下次打开时重新查询；随 JSON 备份和快照保存。删除卡组时清理该卡组限定的筛选。

专项练习从筛选结果取前 1–500 张可用卡片，每张本轮练习一次，跳过暂停 / 今日暂缓，保留原卡组。提供两种模式：

- **只练习，不改进度**（默认）：评分和撤销仅作用于本轮，不写入复习记录，不改变 FSRS 状态、额度、自动暂缓或统计。结束 / 刷新后本轮结果不保留。
- **评分并更新进度**：允许提前复习和超过每日额度；按所属卡组的 FSRS 设置评分，写入正式记录并计入当天用量，触发自动暂缓及顽固卡标记。撤销恢复调度与关联变化。选择「重来」后，本轮不会立即重复，后续进入正常到期队列。

## 批量导入与编辑

在「全部卡片」或卡组页面点击「批量导入」，选择 CSV / TSV 文件或粘贴文本。要求 UTF-8，最大 2 MB、5000 条笔记，支持带引号的分隔符、双引号转义和多行字段。

```csv
type,front,back,tags
basic,hello,你好,英语|问候
reversed,apple,苹果,英语|名词
cloze,法国的首都是 {{c1::巴黎::城市}}。,位于塞纳河畔。,地理
```

`front`、`back` 为必需表头；`type`、`tags`、`format` 可选。`format` 支持 `plain / markdown`，默认 `plain`；缺省类型为 `basic`，标签用 `|` 分隔。整个文件校验通过并预览后才允许导入。默认跳过同卡组中题型、格式、正面、背面均相同的笔记，包含文件内部重复项。示例文件位于 [public/example.csv](public/example.csv)。

勾选卡片后可批量移动所属笔记、添加 / 移除标签或删除笔记。笔记级修改作用于全部关联卡片；复习进度保留。卡片列表每页 50 张，可跨页勾选，改变搜索或筛选条件会清除选择。

## 图片、音频与备份

笔记两面均可添加媒体，每面最多 8 个，每个文件最大 10 MB。支持 PNG / JPEG / WebP / GIF 图片和 MP3 / WAV / OGG / M4A / WebM / FLAC / AAC 音频；具体音频解码取决于浏览器。媒体作为 Blob 独立保存在 IndexedDB，复习评分不重写媒体内容。只有点击保存后才会写入附件。

「数据与备份」提供：

- **完整 JSON 备份**：包含笔记、卡片、标签、额度、复习历史与状态、图片和音频，可移至其他浏览器手动恢复。最大 100 MB，恢复前验证结构、引用关系及媒体完整性，确认后替换当前数据。
- **自动快照**：应用启动 / 使用期间对变化的数据每 30 分钟保存；删除、编辑已有笔记、批量修改、导入与恢复前额外保存。相同版本不重复保存，最多保留最近 10 份。
- **快照恢复**：恢复笔记、调度与引用的媒体，操作前另存当前数据。旧快照到期后，不再被当前数据或任何保留快照引用的媒体才会清理。

媒体 ID 在导入外部备份时重新生成，以免覆盖已有快照引用的文件。内容、媒体写入、版本检查和快照创建均在 IndexedDB 事务内执行，失败时整体回滚。过期标签页的写入会被拒绝，提示刷新。

数据和快照都按浏览器及 origin 隔离。清除网站数据会同时删除卡片、媒体、快照与离线缓存；更换域名、协议、端口或浏览器不会自动迁移数据。自动快照无法替代导出到其他位置的完整备份。

## 离线启动与部署

```bash
npm run build
npm run preview
```

将 `dist/` 部署到 HTTPS 静态站点即可，本机 `localhost` / `127.0.0.1` 也支持 Service Worker。首次联网打开后，在「数据与备份」看到 **离线已就绪**，即可断网重新打开、刷新、制卡和复习。保存过的媒体也可离线使用。可通过支持的浏览器安装为独立 PWA。

生产构建按版本预缓存完整应用页面、脚本、样式及图标；任一资源下载失败不会激活不完整版本。新版本就绪时提示刷新，由用户选择更新，避免复习中突然重载。开发服务器不启用 Service Worker，必须用生产构建验证离线功能。没有运行时 CDN、账号服务或遥测。

## 技术边界与结构

当前全部功能在浏览器运行，**无需后端**；如果以后需要服务端，技术约定为 **Rust**。范围不包含账号、订阅、支付、商业化、云同步或团队协作。

尚未实现 Anki `.apkg` 导入、自定义字段 / HTML 模板、所见即所得富文本编辑器、图片遮挡、嵌套挖空、FSRS 参数训练或大规模卡库性能验证。

```text
src/core/
  model.ts           # v3 笔记 / 卡片 / 媒体模型与卡片生成
  legacy.ts          # 冻结的 v1 校验模型
  scheduler.ts       # 按卡组 FSRS、额度、撤销、自动暂缓与顽固卡
  content.ts         # 安全 Markdown 与数学公式渲染
  authoring.ts       # 选中文字插入挖空
  search.ts          # 组合搜索、常用筛选及专项练习队列
  batch.ts           # CSV / TSV 校验与批量操作
  storage.ts         # IndexedDB 事务、自动快照与媒体回收
  backups.ts         # 包含媒体的可移植备份
  media.ts           # 附件校验
src/i18n/           # 双语词典、语言偏好、格式化与 DOM 回归测试
src/composables/     # 工作空间状态与离线更新状态
src/components/      # 笔记编辑、卡片列表、导入、复习和媒体展示
build/              # 构建时生成预缓存清单与 Service Worker
public/             # PWA 元数据、图标及 CSV 示例
tests/              # 生产构建的浏览器回归测试
```
