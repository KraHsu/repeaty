# Discourse 发布

把一份学习材料发布为论坛主题，或更新先前发布主题的首帖、标题、分类与标签。与 WordPress 发布共用页面容器、控件和确认流程。

## 授权论坛

在「设置 → 连接 → Discourse」输入 HTTPS 论坛地址，允许插件连接此站点，然后点击「开始论坛授权」。打开论坛授权页面，用你自己的论坛账号同意 `read,write` 权限，再把论坛显示的加密结果复制回来，验证并保存。

论坛需允许 User API 授权，账号需具有发帖 / 编辑权限。插件不要求管理员 API key、预置密钥、付费订阅或 OAuth 服务。论坛策略禁止 User API 时应联系该论坛管理员；已有该站点 User API key 也可手动保存。

授权使用一次性的 RSA-OAEP 密钥对和 nonce。私钥只保留在当前设置页面内存，15 分钟过期，离开页面或切换学习库即清理；解密所得 User API key 立即写入设备凭据存储，不写进学习库或备份。学习库移动到另一设备后需要重新授权。

## 发布与恢复

选择材料、调整主题标题，读取站点分类与标签，准备预览；确认内容、目标论坛和公开范围后再发送。分类可受论坛权限限制，帖子最终可见范围由论坛分类权限决定。更新前会核对真正的首帖原文和主题元数据；预览后远端有变更时停止覆盖，要求重新预览。

更新分两步完成：首帖正文、主题标题 / 分类 / 标签。任何一步发送后的失败都可能留下部分成功，插件会要求核对远端状态，再准备下一次更新。取消或超时也不代表论坛已撤销请求；未知结果禁止重复新建。可通过「核对远端状态」或手动填写首帖 ID 恢复，始终验证正文中的 Repeaty 关联标记。删除前需要另行预览确认，删除对象是整个主题及其讨论；本地材料和学习进度保留。

连接地址、发布草稿和远端主题绑定随学习库保存；禁用或卸载保留这些记录和远端主题。设备凭据可以单独移除。恢复较旧备份时会读取当前账号自己的主题活动列表，逐篇核对原始首帖中的确定性关联标记。User API 不支持管理员接口的 external_id，因此不依赖该字段。完整查找最多核对 1000 个主题；超过上限、列表变化或结果尚不可确认时停止新建，保留手动首帖 ID 核对入口。

## 内容边界

仅发送选定材料的公开 Markdown 正文与本次发布设置，不发送整个学习库、复习记录、调度或私有元数据。草稿 / 私有材料不能直接发布。代码语言、表格、公式原始文本保留；实际着色、公式渲染与其他扩展语法由论坛安装的功能决定。

内部材料链接需要先在同一论坛发布目标材料，解析后转换为公开链接；未解析链接、本地路径、原始 HTML 和本地附件会明确阻止发送。此连接器不自动上传附件，请使用公开 HTTPS 图片地址或「静态发布」插件。预览只是内容核对，论坛最终渲染可能不同；公开图片在预览时可能联网加载。

## 开发

在插件目录运行 `npm run typecheck`、`npm test`、`npm run build`。插件独立打包，不需要 Node.js 运行时，不进入 Repeaty 本体构建图。共享 UI、发布快照、联网、取消和设备凭据通过公开 SDK 提供。

接口依据：[Discourse API](https://docs.discourse.org/)、[User API key 授权协议](https://meta.discourse.org/t/user-api-keys-specification/48536)。
