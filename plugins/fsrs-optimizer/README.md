# 个人 FSRS 参数

使用当前学习库的真实复习记录，在设备上的独立 Worker 中训练 FSRS-6 参数。插件无需联网，也不需要 Node.js。训练器和 WebAssembly 文件均随插件安装。

## 使用

1. 安装并启用插件后，打开侧栏「个人 FSRS 参数」。
2. 选择整个学习库或一个卡组。至少需要 1,024 条有效记录、512 个跨日训练样本和 128 个跨日验证样本；未能还原完整起点的旧记录不参与训练。
3. 点击「开始训练」。可随时取消；关闭插件或切换学习库也会终止训练并释放 Worker。
4. 训练只使用较早的 80% 历史。Repeaty 用剩余历史独立核对预测误差（Log loss）和分组校准误差（RMSE），两项都改善才保存候选。
5. 比较训练结果后点击「采用参数」。若历史或当前参数已发生变化，旧候选会被拒绝，应重新训练。单一卡组的参数优先于学习库参数。

采用参数只影响之后的评分与排程，**不会重写既有到期时间、评分或历史**。「恢复上一套参数」恢复该次采用之前的参数；不存在上一套个人参数时回到默认参数或学习库参数。

## 自动训练

在「设置 → 学习 → 复习」中，按学习库或卡组开启「空闲时自动训练」。默认关闭。每新增约 1,024 条记录，软件在前台空闲至少 30 秒且没有进行学习时训练；恢复操作、进入学习或窗口离开前台会取消。

自动训练默认只生成候选。「自动采用通过验证的参数」是另一个默认关闭的选项；明确开启后，仍须满足两个验证指标均改善、记录及作用域未变化，才会采用。关闭或卸载插件保留已保存的模型和学习记录。

## 边界与资源

- 训练目标是个人化预测，不承诺每次训练都更好。样本不足、无改善或验证失败时继续使用原参数。
- 使用 `@open-spaced-repetition/binding-wasm32-wasip1@0.6.0`，显式选择 **FSRS-6 / 21 个参数**，不使用该依赖默认的 FSRS-7。
- Worker 初始 WASM 内存 64 MiB，上限 512 MiB；两分钟超时。单次最多 20,000 段历史、100,000 条记录、50,000 个训练前缀与总计 2,000,000 条前缀记录，每段最多 1,024 条记录。超限会停止，不会截断历史伪造初始状态；可选择较小卡组训练。
- 短期复习保留在历史前缀中，跨日样本用于训练与验证；间隔采用与现有 FSRS 评分一致的 UTC 日界差，原有 FSRS 短期设置由宿主提供。
- Web Worker 不使用共享内存，不要求 COOP / COEP。全部资源由宿主按当前学习库托管；插件不能绕过宿主直接启用参数。

优化器及其 JS 运行时为 MIT / Apache-2.0 等开源依赖，许可证随 `assets/LICENSE.*` 分发。算法和 API 参见 [Open Spaced Repetition 官方文档](https://open-spaced-repetition.github.io/ts-fsrs/guide/optimizer/)。
