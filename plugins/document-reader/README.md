# EPUB 与 HTML 阅读

独立的官方格式插件：在 Repeaty 内离线阅读书籍章节和网页文件，并沿用材料的选区制卡、挖空、摘录、阅读进度与出处回看。运行时不需要 Node.js。

## 导入与阅读

在「学习材料 → 插件导入」选择本插件的入口：

- **EPUB · 自由阅读**：保留书籍目录，按原书 spine 建立章节，可自由选择学习章节。
- **EPUB · 顺序阅读**：同样建立一次章节，先学习第一章。阅读器中点击「完成本章」后，下一章进入学习队列。锁定章节仍可浏览，不会提前进入学习队列。
- **HTML · 网页文件**：导入 `.html`、`.htm` 或 `.xhtml`。需要图片或音频时，同时选择配套资源，保留它们相对于 HTML 文件的目录关系。文档中的 raster data 图片也会保存在学习库内。

EPUB 阅读器提供目录、章内查找、前后章节导航和自由 / 顺序切换。改变模式不会重新创建章节。阅读位置按不可变正文版本和 UTF-16 偏移保存；嵌套格式、中文、emoji 与重复句子的选区都对应原章节，不依赖模糊搜索。点击书内链接可跳到目标章节和锚点。

纯图片封面和媒体章节也会保留，显示原图片 / 音频及明确的文档说明，不进行 OCR；它们不会进入学习队列或阻挡后续章节释放。

选中文字后使用宿主材料页面的制卡 / 挖空 / 摘录操作。复习时可回到该章原版本出处。旧版本与只读查看不提供修改学习顺序或完成章节的按钮。

## 原件与资源

原始 EPUB / HTML 保存在学习库，可通过材料页面导出。EPUB 里的 PNG、JPEG、GIF、WebP 图片以及 MP3、WAV、OGG、M4A 音频，和用户明确选择的 HTML 配套资源，均可离线使用。停用或卸载插件仍保留材料文字、原件、资源、卡片和历史；安装后可恢复阅读器。

HTML 与 EPUB 的可读结构、标题、列表、表格、基本文本样式、MathML、图片和链接会保留。脚本、表单、iframe、SVG、嵌入程序、隐藏内容和活动样式会移除；远程图片和其他外部资源不会自动下载。HTTP(S) 外链由用户点击后打开。HTML 的有效 canonical URL 会作为来源保存。未能加载的资源会在阅读器中提示。

本阅读器采用适合阅读和选区制卡的统一排版，不复刻原书分页、字体文件或整站 CSS。暂不支持 DRM 或包含加密资源的 EPUB，包括仅字体混淆的书籍；此类文件会明确拒绝，原文件不会被修改。SVG 图像应先转换成 raster 图片再导入。

## 文件限制

每份原件不超过 **32 MiB**；解压后不超过 **64 MiB**，单个内部文件不超过 **8 MiB**；EPUB 最多 **99 个正文章节**、5,000 个 ZIP 条目，每章最多 250,000 个 UTF-16 字符；资源最多 512 个。HTML 配套资源同样遵守 64 MiB 总量和 8 MiB 单文件限制。超出范围会中止，不会只导入前半本。解析在宿主管理的 Worker 中进行，可取消，离开页面或停用插件会清理 Worker 和临时对象 URL。

## 独立开发

```sh
npm install
npm run typecheck
npm test
npm run build
```

公开 `@repeaty/plugin-api` 提供构建、通用材料事务、后台任务、资源和共享 UI；插件不导入宿主 `src/`。构建先执行 `prepare:assets` 打包独立解析 Worker，再输出 `dist/document-reader.repeaty-plugin`。插件包可以单独安装和更新，无需重编译 Repeaty。

依赖：zip.js（BSD-3-Clause）与 parse5（MIT），许可文本位于 `licenses/`。
