# 图像与公式遮挡

Repeaty 官方外置插件。它与第三方插件使用同一插件包、材料接口和共享 UI；更新插件无需重编译桌面客户端。

## 图片阅读与区域批注

1. 在学习材料中导入 PNG、JPEG、WebP 或 GIF。每个文件保留原件，材料标题是文件名，不生成 OCR 文字。
2. 使用缩放、适合宽度和旋转查看原图。拖动框选区域后，可通过材料工具条添加批注、制作摘录或制作图片遮挡题。
3. 从摘录或卡片返回来源时，显示保存的图片选区；“显示原图”恢复上下文。“导出选区 PNG”导出裁切结果，“保存原件”保留导入文件原有字节。

区域保存为原图的规范化坐标，不受缩放或旋转影响。定位绑定导入时的材料版本；替换、删除或外部编辑原件不会悄悄重映射旧卡片区域。

## 图片遮挡题

打开图片材料，选择“制作图片遮挡题”。可直接拖出多个矩形，拖动移动，拖动右下角调整大小；也可用数值输入精确调整。选中区域后，方向键移动，Shift 加速。每个区域有自己的名称和独立调度卡片。

“只遮挡当前区域”用于保留上下文；“同时遮挡其他区域”用于避免相互提示。显示答案时仅揭开当前区域。

编辑现有卡片时，移动、改名和调整区域均保留原 ID。退役区域停止出题；编辑器的“恢复”使用原 ID，恢复原调度与完整历史。重新框选一个区域会创建新的卡片。每组最多保存 128 个区域，包含退役区域；最后一个区域不能单独退役，可由宿主删除整条笔记。

## 公式遮挡题

打开 Markdown 材料，选择“制作公式遮挡题”。支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`，不处理代码中的公式。先选一个公式，再在**渲染后的公式上**拖选或点击元素。Shift 连选，Ctrl / ⌘ 多选。每组选区生成一张卡片；编辑时可以替换选区、增加区域、退役或恢复。

公式由包内固定版本 KaTeX 渲染，保存 LaTeX、渲染器版本、DOM 叶子签名和选区索引，不把 LaTeX 字符串挖空当作公式选区。回源会高亮所选公式元素。字体包含在插件中，渲染无需联网。禁用可信 HTML/链接命令并限制展开量。若未来渲染器版本或结构不匹配，显示明确错误，避免遮挡错误内容。

## 数据与限制

- 原图最多 10 MiB、4000 万像素，单边最多 20000 像素；不支持 SVG 等主动内容。动画图片仍为动画，适合静态截图的遮挡内容请先导出静态图。
- 单个公式最多 8000 字符，工具一次列出前 200 个公式；可选择渲染后的文字叶子。分数横线等纯几何装饰不作为独立选择项。
- 开关、卸载和插件缺失不会删除材料、遮挡数据或学习历史。缺少插件时保留普通题目与原始答案兜底；图片原件仅在答案侧引用。
- 插件不联网、不读取凭据，也不直接访问文件系统。宿主负责导入、原件、制卡、批注、撤销、版本和工作目录事务。
- 需要含材料命令组件、公式定位和稳定插件变体的新版 Repeaty SDK。安装旧宿主前请核对其插件能力。

## 开发

在仓库根目录安装依赖后，运行 `npm run typecheck --workspace @repeaty/plugin-visual-occlusion`、`npm test --workspace @repeaty/plugin-visual-occlusion` 和 `npm run build --workspace @repeaty/plugin-visual-occlusion`。输出独立 `.repeaty-plugin` 插件包。

KaTeX 采用 MIT 许可，见 `LICENSE-KATEX.txt`。样式仅保留 WOFF2 字体，以控制独立插件体积。
