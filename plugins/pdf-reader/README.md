# PDF 阅读器

把 PDF 原件保存在当前学习库，离线阅读、搜索，并从原文选区创建摘录、卡片和挖空。与其他插件一样，按学习目录安装；停用或卸载不会删除已保存的材料、卡片或学习记录。

## 使用

1. 在插件页安装并启用 PDF 阅读器。
2. 在学习材料页导入 `.pdf` 文件，核对导入预览后确认。
3. 阅读工具栏提供页码跳转、上一页 / 下一页、适应宽度、50%–300% 缩放、顺时针旋转和章节内搜索。
4. 在原文上选择文字，可跨栏、跨页。使用材料页共用操作创建摘录、普通卡片或挖空。回到原文时，会按材料版本和页面区域恢复高亮。

缩放和旋转按当前学习库、原件和材料版本分别记忆；阅读位置由宿主保存。材料全文搜索结果也可直接定位到 PDF 对应文字，并精确高亮匹配范围。只读回源使用默认视图，不读取或改写文档视图偏好。

每段材料最多 50 页、250000 字符和 60000 个文字对象，超过时仅在整页之间分章。分章共用一份原件，并在文档目录中列出。分章不会截断页面文字；搜索范围为当前章节，最多显示 500 个匹配结果。

## 边界

- 单份 PDF 原件最大 64 MiB、2000 页、8000000 个文字字符和 400000 个文字对象。超过限制会说明原因，不会静默丢弃内容。
- 每次文字选区最多 10000 个字符和 256 个页面区域。页内坐标以未旋转的裁剪框归一化，改变缩放或旋转不改变已保存选区。
- 扫描件与图片页可以阅读原图；没有文字层时明确显示提示，本插件不提供 OCR。
- 加密文档需先保存已解除密码保护的副本。损坏文档会报告失败。阅读原件暂不可用时，可以查看学习库保存的文字投影。
- 不执行 PDF 中的 JavaScript、表单交互或外部链接，不下载远程字体或解析资源。字体、CMap、WASM 和 Worker 均来自插件包。
- 大图按画布预算绘制；离屏画布释放，文字层保留以支持连续选区。切换材料、取消、停用、卸载和切换学习库都会释放解析 Worker 与其他阅读资源。

## 开发与验证

插件仅依赖公开 `@repeaty/plugin-api` 与 Vue。`npm run build` 独立生成 `dist/pdf-reader.repeaty-plugin`；`prepare:assets` 将 PDF.js 离线依赖复制进包。软件本体不编译本插件源码。

运行 `npm test` 和 `npm run typecheck`。真实 Chromium 验证可在完成构建后运行 `node test/browser.mjs`，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chromium。该测试加载最终插件包，验证真实 Worker、中文双栏、裁剪 / 旋转页、跨页选区、搜索与资源清理；不作为 Windows/macOS/Linux 原生窗口验收。
