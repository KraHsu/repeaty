# 静态发布

把明确选中的学习材料生成可独立托管的静态网站。插件以独立包安装，不进入 Repeaty 本体编译图；生成和导出可以在无后端网页版使用，Cloudflare Pages 连接使用桌面版的通用网络与设备凭据接口。

## 使用

1. 在「插件」安装并启用「静态发布」，主侧栏会出现同名入口。
2. 在「设置 → 工具 → 发布」填写站点标题、说明、公开地址和每页数量。公开属性默认空白，按名称明确填写，例如 `tags, category`。
3. 在静态发布页面勾选材料并生成预览。生成只写本插件的本地站点，不上传内容、不修改学习记录。
4. 检查首页、文章、归档、标签、分类和搜索。导出 ZIP 后解压即可在本地浏览器打开 `index.html`，或把全部文件上传静态托管。
5. 正式托管前填写真实 HTTPS 公开地址，RSS 和站点地图据此生成永久链接。留空时仅用于本地预览，链接使用 `example.invalid` 占位。

取消材料勾选并重新生成，会从新站点移除其文章；本地绑定保留，以后重新选择仍使用原有公开路径与首次发布时间。全部取消可生成空站。已有远端站点只有在确认部署新版本后才改变。

## 公开边界与本地记录

- 只读取选择列表中明确选中的材料。标题与正文会公开，正文内手写的敏感信息不会被自动识别；生成前请检查内容。
- 草稿、私密材料不可生成。材料的 frontmatter 不直接输出，只有「公开属性」中明确列出的标量或文字列表进入模板、搜索与页面；凭据、内部 ID、路径和保留字段不能作为公开属性。
- 内部材料链接和 wiki 链接只连接到本次同时选中的文章；其余显示为普通文字。标题有重名时使用明确材料链接。Markdown 标题生成可跳转的片段锚点，重复标题追加数字。
- 仅输出所选正文实际引用、由宿主投影的本地图片、音视频与 PDF 附件。未选择的文档原文件、历史版本、私有设置、设备凭据和库 ID 不进入 ZIP、RSS 或搜索索引。外部图片或媒体不会自动下载，生成会提示先导入本地附件；不会悄悄省略它们。
- 文章路径为 `articles/公开数字/index.html`，与学习库内部标识分离。新内容的更新时间变化，重复生成不刷新未变更文章的时间。
- 生成产物、文章绑定和选项保存在当前学习库的插件数据中；凭据和代码信任保存在当前设备。启停、卸载或切库遵循宿主的资源回收与数据保留规则。
- 失败、取消和主题错误保留上次完整站点。重载后可以继续查看旧站，但必须重新生成才能导出或部署；学习库变更、切库或十分钟快照过期也要求重新生成。

## 主题

设置中可独立编辑 `page.html`、`archive.html`、`style.css` 与 `site.js`，也可确认恢复默认绿色阅读主题。保存配置不立即替换站点，生成成功后才更新预览。主题源码只是插件数据，不需要重新编译软件或插件。

HTML 使用受限 Liquid 模板：默认转义文本，`{{ page.content | raw }}` 用于宿主投影并清理后的文章 HTML。可使用条件、循环、常用过滤器；缺失变量、未知过滤器及语法错误显示文件、行列位置。禁止文件系统访问和 `include`、`render`、`layout`、`extends`、`import`，不提供库对象、凭据、进程、网络或 Node.js API。生成与 ZIP 压缩在可终止 Worker 中完成，并限制模板长度、运算和产物体积；这是受限公开模板能力，不是任意不可信代码的通用隔离执行环境。

主要变量：

| 范围    | 字段                                                                                                                                                                                            |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `site`  | `title`, `description`, `url`, `topics`, `home_url`, `archive_url`, `rss_url`, `tags_url`, `categories_url`, `search_url`                                                                       |
| `page`  | `view`, `title`, `depth`, `is_home`, `content`, `fields`, `topics`, `terms`, `published_at`, `updated_at`, `newer`, `older`, `previous_page_url`, `next_page_url`，以及相对当前页面的各入口 URL |
| `topic` | 公开 `id`, `title`, `path`, `content`, `excerpt`, `published_at`, `updated_at`, `fields`                                                                                                        |
| `field` | `key`, `values`（文字列表）                                                                                                                                                                     |
| `term`  | `name`, `path`, `count`                                                                                                                                                                         |

`page.view` 为 `home`、`article`、`archive`、`tags`、`categories`、`tag`、`category` 或 `search`。仅归档页使用 `archive.html`，其他页面使用 `page.html`。通过 `page.depth` 为站点根目录下的资源生成相对路径，以支持子路径托管和本地文件浏览。

应用内预览使用独立 sandbox iframe，支持站内导航和默认搜索；禁用自定义主题脚本、外部链接和外部资源。导出包保留 `site.js`，默认搜索读取本地 `search-index.js`，无需联网或搜索后端。自定义 JavaScript 应在导出后的独立浏览器页面验证。Markdown 支持代码高亮、中文强调、受控内嵌 HTML 与 MathML 数学公式；默认主题不依赖外部字体服务。

## Cloudflare Pages

在设置中填入 Cloudflare Account ID、项目名称、部署分支和具有该账号 Pages 编辑权限的 API token。Token 只写设备凭据，输入框不回填；学习库移动到另一台设备时需要重新设置。保存连接、检查/创建项目与实际部署是不同操作，创建项目不会上传材料。

先生成并检查预览，再点击发布，确认可见的项目与分支。上传使用内容指纹与 Cloudflare Direct Upload；插件持久记录部署状态。如果提交期间断线、取消或应用退出，先使用「核对远端状态」，不会因结果未知而直接再建一次部署。结果尚未确定时不能更换目标；界面保留目标与最近状态。

「删除远端项目」会删除整个 Pages 项目和全部部署，需要输入项目名称并再次确认。它保留本地学习材料、站点及绑定。没有本插件部署记录的项目应在 Cloudflare 控制台管理。

本插件不提供自动发布、域名购买、站点同步或收费服务。手动部署只在用户确认后发生。

## 限制与开发

单站最多 500 篇材料、64 MiB 产物、5000 个文件；单文件最多 8 MiB，单材料正文最多 4 MiB，每份主题最多 256 KiB，历史文章绑定最多 10000 条。宿主还应用自己的材料、附件和快照限制。超限会保留旧站并提示缩减内容。

```sh
npm run typecheck --workspace @repeaty/plugin-static-publish
npm run test --workspace @repeaty/plugin-static-publish
node packages/plugin-api/build.mjs plugins/static-publish
```

产物位于 `dist/static-publish.repeaty-plugin`。生成器与 Cloudflare 资源准备 Worker 都随插件包独立分发；依赖许可证包含在包内 assets/licenses。SDK 要求 Repeaty 插件 API 1.14 或更新版本。
