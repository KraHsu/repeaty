# 学习助手

围绕选定的学习材料提问、比较内容或准备整理建议。助手使用 Repeaty 的公开 SDK，与第三方插件使用同一安装、授权和启停流程；更新插件无需重新编译 Repeaty。

## 开始使用

1. 在插件页安装并启用“学习助手”。
2. 到 **设置 → 连接 → 学习助手** 添加连接。支持兼容 OpenAI 的 API，也支持已安装的 Codex app-server。
3. 打开侧栏的“学习助手”，新建对话，选择材料、目录或整个学习库。授权前不会把学习库正文交给模型。
4. 输入问题。需要整理或编辑时，勾选允许修改建议；助手只准备建议，检查具体修改并确认后才应用。

API 连接需要提供方的 API 地址、模型 ID 和自己的 API key。访问权限、费用和限额以该提供方账号为准。Codex 连接使用独立的设备会话，可在设置中登录、退出和读取可用模型；不执行插件提供的 shell 脚本，不要求系统安装 Node.js。

## 对话与图片

对话支持续聊、另开续聊、归档、软删除与恢复。草稿和消息保存在当前学习库的插件数据中。中断或服务失败时保留已收到的回复和输入；未完成的工具调用不会在下次请求时伪装成已完成。

每条消息可附加最多 3 张 PNG、JPEG 或 WebP 图片，每张不超过 3 MB。图片按插件文件分片保存，只有发送消息时才交给所选提供方。可以附带当前阅读选区，也可以明确粘贴希望讨论的段落。

本地保留完整对话。单次模型请求使用最近最多 197 条消息和最近 3 张图片；超长消息按字节缩短，界面会显示本轮实际发送范围，模型也会收到省略说明。需要讨论较早的图片或内容时，可重新附加或重述。长篇材料通过受授权的正文分页读取，每页最多 20,000 字符，不会为了模型输入限制修改原始材料。

## 范围与修改

模型工具只通过宿主的授权桥读取或提出修改。材料、图片和模型输出不能扩大授权范围。切换对话、离开页面、切换学习库和停用插件会撤销当前页面的授权并停止旧操作；重新开始前可再次选择范围。

新对话默认不读取学习库；范围选择默认是“所选材料”，修改建议默认关闭。可以只授权所选材料或目录来问答；勾选允许修改建议后，也仍需逐批确认应用。引用集合可能跨多个目录，因此查询、增删引用、重排、归档和恢复集合需要用户明确授权整个学习库；不会因模型请求集合工具而自动扩大范围。

修改建议显示实际操作、对象和待写入内容。应用仍由宿主核对授权、学习库修订和不可变预览，再进入与软件其他入口相同的事务。过期建议不会覆盖较新的学习数据。结果返回中断时使用原操作 ID 查询回执，不另建同内容的写入。

## 保存位置与能力边界

- 插件代码、对话、草稿和图片按学习库保存。卸载或停用不会删除学习数据或插件数据。
- 连接配置与凭据只保存在当前设备；API key 不写入插件设置、对话、学习库备份或工具输出。换设备后需要重新配置连接。
- 当前模型连接需要桌面版。网页仍可查看已有对话与草稿，但不会声称已连接原生模型提供方。
- 提供方必须支持所用的文本、图像和工具协议。连接测试的结果不能证明所有模型均支持每种能力。
- 调用模型可能把所选材料或图片发送给提供方。选择范围时只包括本次需要讨论的内容。

## 开发

从项目根目录运行 `npm run typecheck --workspace @repeaty/plugin-assistant`、`npm test --workspace @repeaty/plugin-assistant` 和 `npm run build --workspace @repeaty/plugin-assistant`。插件产物通过公开插件包安装；源码不进入软件本体构建。
