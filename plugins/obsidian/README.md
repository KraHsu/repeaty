# Obsidian 来源

将已有 Obsidian 笔记库作为 Repeaty 的只读材料来源。在学习材料的来源管理中选择“Obsidian 笔记库”，授权目录并检查；新笔记、修改和缺失项先进入待确认列表，采用后才写入当前学习库。

## 笔记与附件

- 读取 `.md` 笔记，排除隐藏目录、`.obsidian`、`.git`、临时文件与宿主拒绝的符号链接。不会修改或移动原笔记。
- 支持 `[[笔记]]`、`[[目录/笔记#标题|别名]]`、标准 Markdown 相对链接与本地图片/音频/PDF 附件。重复短文件名保持原文，避免连接到错误笔记。
- 代码块和行内代码中的链接示例保持原样。嵌入笔记转换为可打开的材料链接，不递归复制笔记正文。块引用保留锚点；跨应用不支持的 Obsidian 特性仍保留原始文字。
- 来源身份使用笔记库内相对路径。重复检查不会建立第二份材料；改名、删除和重新关联通过宿主候选流程处理，不猜测同名文件身份。

一次最多 1,000 篇笔记、128 MiB 内容；单篇最多 250,000 字符，单个附件最多 10 MiB。超限或读取失败时整次检查失败，不以半份快照删除材料。可将大库分为多个子目录连接。

## 生命周期

停用、卸载或断开来源不删除已采用的材料、卡片、批注、评分与旧版本。重新连接后再次检查即可。目录授权保存在此设备；学习库移动到另一台设备后需要重新授权。

这是单向只读接入，不向 Obsidian 写回，也不要求安装 Node.js。插件与软件独立更新。

链接语法依据 [Obsidian 官方说明](https://obsidian.md/help/links)。
