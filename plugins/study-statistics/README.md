# 学习统计

按学习日查看实际学习记录和当前保存的安排。安装并启用后，侧栏会出现“学习统计”，采用 Repeaty 的统一页面容器、控件、绿色主题和深色模式。

## 查看日历

月份范围为过去五个月、当月和未来六个月。点击日期查看明细；使用方向键切换日期，Page Up / Page Down 切换月份，“今天”返回当前学习日。

- **正式评分**：成功保存的卡片评分次数。重复保存同一条记录不会重复计数，撤销评分后对应记录会移除。
- **阅读完成**：完成阅读动作的次数，不是打开材料的次数。
- **纯练习**：完成但不改变正式调度的练习次数，包含普通卡片和插件练习。未完成的尝试不计入。
- **前台使用**：窗口处于前台且用户活跃时累计的时间。阅读、复习和练习时间是总时长的组成部分；后台停留、最小化和长时间无操作不算学习时间。

尚未开始记录的时期显示“—”，不会把缺失数据当作零。月度汇总只累加已有记录。学习日默认从本地午夜开始，可在设置里调整；已保存的评分和阅读事件保留当时的学习日。

## 实际记录与计划

过去日期显示已保存的实际记录，未来日期显示当前卡片到期日和材料可用日期。今天可以同时查看记录与计划。逾期项目归入今天；暂停、不可用卡片，以及 Inbox、归档、已完成、被阅读顺序锁定的材料不计入当前计划。

计划不是对未来评分的预测，也没有扣除每日额度。完成学习、调整日期或修改材料队列后，未来安排会变化。点击“刷新统计”可重新读取；切回窗口、学习日边界和记录变化也会刷新。

## 数据与管理

插件只通过公开只读 SDK 读取当前学习库的摘要和分页明细，不读取练习完整代码，不需要联网、凭据或 Node.js。插件安装在当前学习目录；停用或卸载会移除页面和侧栏入口，保留评分、阅读、练习和前台时间记录。重新安装后可继续查看。

此插件独立于“复习热力图”，两者可分别安装、停用或卸载。

## 开发

在仓库安装依赖后运行 `npm run build --workspace @repeaty/plugin-study-statistics`，通过公开 SDK 独立构建插件包。软件本体不编译此插件源码。
