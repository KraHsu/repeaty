# 格式清理

独立安装的官方插件。安装并启用后，从侧栏「格式清理」选择文本或 Markdown 材料，点击「预览清理」，对比清理前后的完整正文，再点击「应用清理」。

在「设置 → 工具 → 格式清理」配置行尾空白、空行、缩进和最多 32 条文字／正则替换。文字替换将 `$1` 等作为普通字符；正则在完整正文上按 JavaScript Unicode 全局匹配，支持 `i`、`m` 和捕获组替换，保留锚点、前后查找的真实上下文，跳过与保护区域重叠的匹配。规则按顺序执行，替换过程中持续检查长度，不先构造超大结果。

代码围栏、缩进代码、行内代码、链接地址、引用地址、HTML 标签和 YAML 前置属性始终受保护。为避免破坏 Markdown 语义，两个空格的硬换行保留；缩进代码及深层缩进宁可保持原样。不更改 PDF 等格式的原件。

正则在宿主管理的 Worker 中运行，超过 2 秒自动终止。插件停用、切库或关闭页面会取消未完成的预览。预览期间材料或学习库发生变化时，应用会拒绝旧结果，需重新预览。

应用后创建新的不可变材料版本，通过应用的撤销／重做恢复。旧摘录、卡片、评分、历史、原始版本和草稿保留。插件停用或卸载不会删除材料或清理记录。本插件不需要网络、文件或凭据权限，不能自动批量改写整库。

开发：`npm run build --workspace @repeaty/plugin-format-cleanup`。使用 SDK 1.9 的 `materials.editContent`，在 Repeaty 更新后独立构建和分发。
