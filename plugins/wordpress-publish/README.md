# WordPress 发布

把选定的学习材料发布为 WordPress 文章。插件先显示发送正文、目标站点和新建 / 更新操作，经你确认后才发送；再次发布同一材料会更新已绑定的文章。

## 连接站点

在「设置 → 连接 → WordPress」输入 HTTPS 站点地址并允许插件连接此站点。自建 WordPress 选择 REST，使用用户名和为 Repeaty 签发的应用密码；WordPress.com 可选择 XML-RPC，使用该服务支持的应用专用密码。不要输入日常登录密码。站点禁用接口、应用密码或账号缺少权限时，连接会失败，不会自动改用其他服务或要求订阅。

XML-RPC 可留空 Blog ID，由插件在此账号可访问的站点中匹配完整地址，也可手动指定。连接地址和 Blog ID 随学习库保存；应用密码仅保存在当前设备的凭据存储。移动学习库、重新安装设备或删除凭据后需重新连接。

## 发布与维护

1. 从侧栏进入「WordPress 发布」，选择一份材料。可调整文章标题、草稿 / 公开 / 私有状态。
2. 读取站点分类和标签；分类和标签均按名称选择，不需要手工填写内部编号。
3. 准备预览，核对正文、站点和状态，勾选确认后发送。已有文章会显示远端当前正文供比较。
4. 远端页面有改动时，原预览失效，需要重新核对。删除操作另行预览、确认；本地材料、卡片和学习进度保留。REST 删除使用站点回收站，不强制永久删除。

断网、超时、停止等待或关闭页面可能发生在站点已经收到请求之后。插件保留待核对记录，禁止直接重复新建；使用「核对远端状态」恢复。自动查找失败时，可输入文章 ID，插件仍会验证该文章确实属于当前材料。确认前不要手动删除文章末尾的 Repeaty 关联标记。恢复较旧的学习库备份后，确定性关联标记仍用于寻找原文章；XML-RPC 完整查找上限为 1000 篇，超过时停止操作，避免把未查到误判为不存在。

## 内容边界

只发送选中材料的公开正文与这次填写的发布信息；不发送调度、复习记录、私有元数据、整个学习库或设备凭据。草稿 / 私有材料不能直接发布。Markdown 保留标题、列表、表格、引用、加粗和代码语言 class；公式按原始公式文本保留，远端公式渲染和代码着色由站点主题 / 插件决定。纯文本按文本转为段落。

内部 Wiki / 材料链接只有在目标已发布到同站点且可安全解析时才转换为公开链接；未解析的内部链接、原始 HTML、本地路径和附件会明确阻止发布。此连接器不自动上传本地图片、音频或其他附件；可改用公开 HTTPS 图片地址，或使用「静态发布」插件完整导出附件。公开图片在预览中可能向图片站点发起加载。

插件卸载和禁用不会删除远端文章、本地材料或发布关联；重新安装后可继续核对。删除设备凭据不会解除已有文章绑定。

## 开发

在插件目录运行 `npm run typecheck`、`npm test`、`npm run build`。它独立打包共享发布客户端和 Markdown 渲染器，只通过公开 SDK 使用页面容器、设置组件、发布快照、联网与设备凭据能力，不依赖 Node.js 运行时，也不进入 Repeaty 本体构建图。

接口依据：[WordPress REST Posts](https://developer.wordpress.org/rest-api/reference/posts/)、[REST 认证](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/)、[WordPress XML-RPC](https://developer.wordpress.org/apis/xml-rpc/)、[WordPress.com 应用专用密码](https://wordpress.com/support/security/two-step-authentication/application-specific-passwords/)。
