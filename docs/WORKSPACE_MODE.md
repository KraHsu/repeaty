# 桌面工作目录

Repeaty 以桌面客户端为主要产品。一个学习库对应一个文件夹，客户端直接打开它；不再在桌面端区分本地学习库与上游账号模式。在线页面在无后端的前提下尽可能展示可用能力；通过浏览器接口、针对性的适配或 WASM 补足部分原生能力。同步服务另行设计。

本轮按项目尚无其他使用者处理，直接建立新格式，不开发旧 IndexedDB、上游账户或实验目录的迁移和双写机制。程序不会自动读取、删除或覆盖旧库。M0 文档与测试保留为协议实验记录，不代表正式目录支持这些实验格式。

## 使用

在侧边栏「工作目录」中选择空文件夹创建学习库，或打开已有的 `workspace.json` 所在文件夹。新建库自动添加入门卡组。下次启动会重新打开上次选择的目录；目录不可用时显示重新打开入口，不创建替代库。

关闭目录前会等待正在保存的操作。重新打开、切换与重启都会取得新会话；旧页面的延迟请求不能写入新目录。同一学习库不能由两个客户端进程同时编辑。

```text
我的学习库/
├── workspace.json             # 目录格式与学习库身份
├── notes/*.md                 # 卡片正文，含稳定笔记身份
├── sources/*.md               # 材料正文
├── assets/                    # 可外部编辑的图片、音频
└── .repeaty/
    ├── state.sqlite3          # 卡组、卡片映射、FSRS、复习与代码记录
    │                          # 阅读位置、检查点、AI 草稿、偏好与代码草稿
    ├── objects/<sha256>       # 已接受的 Markdown 原字节
    ├── media/<sha256>.<扩展名> # 不可变的正文、图片和音频快照
    ├── staging/               # 待发布正文
    ├── retained/              # 替换下来的原文件
    └── workspace.lock         # 打开期间的写锁
```

正式目录标记格式为 3，产品版本仍为 0.27.0。格式 1 / 2 属于此前未发布的接管实现，当前不自动迁移；测试时请创建新目录。SQLite 的内部结构编号不另作产品版本。

材料扩展使用学习库 payload 15、JSON 备份 15 和 `.repeaty` 归档清单 12（`libraryVersion: 15`）。现有正式目录的 SQLite 结构 10 可继续读取，打开目录不会改写已有学习记录。第一次成功保存材料原件信息、跨格式定位、父子关系或材料操作收据时，同一 SQLite 事务将 `user_version` 至少提升为 11；第一次保存持久撤销/重做记录或附件回收状态时至少提升为 12；第一次保存材料文件夹、属性、批注或材料草稿时至少提升为 13。取消、验证失败或事务回滚不会提升。版本不会回退，旧客户端会拒绝打开，避免未知数据被旧写入器覆盖。`workspace.json` 标记仍为 3，并不表示旧应用能读取新的内部结构。网页只读打开接受内部结构 10 / 11 / 12 / 13，不写原目录；独立浏览器学习库使用 IndexedDB 19，旧版本写入器受到浏览器版本检查阻止。

材料扩展保留不可变原件与可独立阅读的文本投影，记录提供方、可选阅读器和格式版本。定位器绑定材料 ID 与文本投影版本 ID；支持文本范围与引用、PDF 零起始页码和多页归一化区域、EPUB 章节位置、图片归一化区域。阅读位置、材料摘录和制卡出处共用该绑定；修改正文产生新版本，旧原件、旧摘录与旧阅读位置仍指向原版本。父子组织关系独立于版本，删除父级时解除关系而保留子材料。普通图片/音频附件接口不把 PDF、EPUB 或通用原件当作可播放媒体。

材料操作收据与业务记录一起提交，并按学习库、插件与操作身份保留结果，撤销不删除收据。整库 JSON / `.repeaty` 导出携带收据；将备份导入为新的内容身份时清空收据，同时重映射原件和全部定位器的媒体版本引用。原件缺失、定位版本不匹配和同一版本身份的文档元数据重写会被拒绝。插件缺失时，文本投影和原件仍属于学习库，不依赖安装代码才能保存或导出。

## 保存与备份

材料正文可在阅读页直接编辑。编辑草稿单独保存，不改动学习库修订号或正文；点击「保存为新版本」后，正文、版本和草稿消费一次提交，并支持持久撤销/重做。普通网页的 IndexedDB 与桌面目录保留草稿；浏览器只读试用将原目录中的草稿读入独立副本，修改仍只在本次页面会话中。正文版本变化时旧草稿不会自动覆盖新正文。

文件夹和材料父子关系使用稳定 ID，改名、移动、排序不会改变内容身份、摘录出处或学习记录。删除文件夹会将内容移到上一级。文字批注绑定正文版本和 UTF-16 原文范围；正文修改后，批注、摘录和卡片出处仍可查看原版本。Markdown 预览选择会映射回原文；无法精确映射的 HTML/数学内部选区提示改用原文，不猜测引用位置。

自定义 YAML 属性在材料文件中保留，可在正文编辑器修改，在统一设置中选择展示字段；`repeaty`、`title`、`url` 通过专用字段管理。检索索引由 Worker 按需建立，可重建、可丢弃，不属于学习库权威数据，也不在普通评分时读取全库正文。同义词只扩展检索。Wiki 链接支持 `[[标题]]` 和 `[[source:材料ID|显示文字]]`；重名标题由用户选择，稳定 ID 链接在改名后仍能解析。

应用内制卡、编辑、评分、撤销、材料阅读和 AI 草稿使用同一个 Rust 存储。正文进入 Markdown；学习状态、映射与增量历史进入 SQLite；附件单独存为文件。评分只更新发生变化的记录，不扫描或重写整个正文目录。

SQLite 接受记录与正文发布意图在同一事务提交。文件以完整候选文件发布，实际被替换的原文件保留在 `retained`；中断后重新打开会处理待完成的发布。外部文件不符合保存时的基线会报告冲突，不按旧缓存覆盖。

手动复制或移动目录前请先关闭学习库，并包含 `.repeaty` 和 `assets`；只复制 Markdown 不包含学习进度。正在打开的 SQLite 可能存在 WAL 文件，不把热复制当作可靠备份。应用里的 `.repeaty` 导出用于当前学习内容交换，不包含退役记录、待确认草稿和完整目录状态。桌面「数据与备份」另提供 `.repeaty-workspace` 完整备份，可在库打开时创建一致快照，恢复到新目录；没有活动库时也可从「工作目录」进入恢复。独立备份目标、分层保留、正文搜索、附件回收站和失败边界见[完整工作目录备份与恢复](WORKSPACE_BACKUP.md)。

桌面与独立浏览器学习库按库保存最近 20 步撤销和 20 步重做，修改与操作记录同事务提交。重启后仍可使用顶部按钮、`Ctrl / ⌘ Z`、`Ctrl / ⌘ Shift Z`（或 `Ctrl Y`）。新操作会清空重做；评分重做沿用原记录与调度，不重新评分或重复调用外部服务。文本编辑器自己的撤销、只读目录的临时试用副本和整库恢复仍各有原来的作用域；整库替换会清理不再适用的操作历史。

## 外部 Markdown 编辑

外部编辑器可修改和改名已有笔记正文。外部保存后，「工作目录」自动列出变化，并在侧栏显示待处理数量。可比较磁盘文件与已接受版本，再接受修改。接受时复用原笔记和卡片身份，不重置当前调度；BOM、CRLF、YAML 注释和无关属性尽量按原字节保留。

新增笔记可以直接放入 `notes/`。问答和双向卡的题面与答案用单独一行 `<!-- repeaty:answer -->` 分隔；挖空卡可直接写 `{{c1::答案}}`。重新扫描后选择「接受修改」，确认卡组、题型和格式。普通 Markdown 或缺少身份的文件会取得稳定笔记 ID 并写回原文件；已有 YAML 注释、无关属性与 BOM / CRLF 尽量保留。带 `repeaty.id` 的文件沿用原身份。

方向和挖空编号发生变化时，确认页会显示保留、恢复、新增和退役数量。已有卡片保留当前调度；新增变体才创建新卡；移除的变体退出学习队列，代码、评分和练习记录保存在同一个 SQLite 中。重新添加相同变体时恢复原 Card ID、调度和历史。桌面应用内的编辑也使用这套规则。

外部删除文件后，重新扫描并确认「移除这条笔记」才会退出学习队列。「已移除的笔记」可搜索、分页和恢复，原路径已有其他文件时可指定另一个 `notes/` 路径。应用内删除笔记或卡组也保留笔记记录；原卡组已删除时，可在恢复确认页选择另一个卡组。保留在操作历史中的删除可跨重启撤销；超出操作历史范围时仍可通过移除列表恢复。

确认前会再次核对工作目录中的文件观察结果，防止把已改名或刚恢复的文件当成已删除。非法内容、重复身份、无法完整扫描或路径碰撞会停止操作，失败的事务不会留下半份退役记录。仅改变记录顺序时在 SQLite 中调整位置，不读取、传回或改写未变的 Markdown 和代码正文。

### 材料版本

`sources/` 支持新建、修改和改名 Markdown，在工作目录页比较并确认「接受修改」。普通 Markdown 可以登记为材料，不要求先建卡组。只改标题、来源链接或文件名时，正文版本和当前位置保持不变。

正文、格式或引用附件变化时，材料 ID 不变，保存新的快照。阅读安排、优先级、间隔、卡片调度和评分仍归属原来的学习记录；新版从头阅读，旧版的位置保留在「历史版本」中。旧摘录、卡片出处和已接收的 AI 草稿绑定原快照，不将旧偏移套到新文字上。查看历史版本不会改变当前阅读位置。

编辑摘录正文后，它成为由原文编辑而来的内容，仍可查看最初出处；旧版逐字摘录继续保留。新的文字不再被当作原文中一段完全相同的引文。

### Markdown 图片和音频

将文件放进 `assets/`，在笔记或材料中使用相对路径，例如：

```markdown
![示例](../assets/example.png)

<audio src="../assets/example.wav" controls></audio>
```

支持 Markdown 图片、引用式图片，以及 HTML 的 `img` / `audio` / `source`。路径相对于该 Markdown 文件；子目录可以使用 `../../assets/`。支持的格式与应用内附件一致，单文件不超过 10 MiB，单文档最多 64 个地址、合计 50 MiB。代码块中的示例不作为附件读取。

接受时将附件字节存为独立快照。直接替换 `assets/` 下的同名文件后，重新扫描并选择引用它的文档，页面会提示附件变化，再确认接受。笔记更新当前附件；材料生成新版本，旧版和旧摘录继续读取原附件。未接受或缺失的文件不会悄悄改变正在学习的内容。目录外路径、链接文件和不支持的格式会停止接受，远程资源不会自动下载。

附件在后台分批检查，选择文档时也会核对当前附件，正常评分不读取工作附件。接受前和 SQLite 提交中再次检查已观察的字节；文件发生竞争修改时保留原学习状态。批量附件管理与同步仍待后续。

目录扫描有文件数、深度和字节限制，并在线程 / Worker 中处理。扫描不完整、路径不安全或内容无效时停止处理，不把未读到的文件当成已删除。文件内容以文本展示，不执行其中脚本。

## 自动检测

客户端监听 `notes/`、`sources/` 和 `assets/`。连续保存会合并检查；应用自己发布的正文、私有数据库与编辑器临时文件不会作为待接受修改提示。文件列表打开时自动刷新，其他页面可从侧栏数量查看变化；正在复习的题面保持原样。

后台按变化路径读取 Markdown，只向解析 Worker 传递变化的正文，未变内容复用已有解析结果。附件只读受影响文件，分批核对摘要。返回窗口、恢复显示、监听队列溢出或手动「重新扫描」会完整补检；后台检查不接受内容、不生成卡片或评分。

确认页使用打开时的内容，自动检测不会覆盖已填写的选项。弹窗期间文件再次变化，保存会拒绝陈旧版本；关闭弹窗后可查看最新修改。移除或接受前仍会完整核对实际文件，监听事件本身不是删除依据。

系统监听暂不可用时仍可手动重新扫描，返回窗口也会补检；学习库原有内容继续保留。关闭、切换或重载目录会结束旧监听，旧回调不能更新新会话。

## 随目录携带与留在设备上的数据

随目录保存：卡组与卡片、调度与历史、阅读安排与位置、材料快照与附件、MCP 待确认草稿、LeetCode 未提交代码、语言、通知、答题历史及插件开关。

留在设备上：最近目录列表、窗口配置、MCP 访问授权、LeetCode 登录凭据。复制学习目录不会复制登录信息；新的设备需要重新授权。工作目录内的插件数据不会授予原生执行权限。

目前没有文件同步引擎、云服务或订阅。本轮不部署私有 IAM 服务，也不改动已安装的客户端。

## 无后端在线工作目录

网页沿用共享 Vue 界面、内容模型和学习逻辑，尽可能提供可操作的体验。现有制卡、编辑、FSRS 复习、阅读与摘录、媒体渲染、导入导出和前端插件继续保留。需要原生支持的能力逐项适配，不要求先建立服务器或另维护一套产品。

本分支已支持「工作目录 → 打开本地工作目录」。先在桌面版中关闭学习库，再选择包含 `workspace.json` 的整个文件夹。网页只读取得文件，在浏览器内解析和展示，不上传学习内容，不取得源目录写权限。

读取成功后先预览卡组、卡片、材料和复习记录数量，点击「开始试用」才切换。现有网页学习库保留，可随时返回。试用中可以复习、编辑、阅读、查看历史和导出 `.repeaty`；评分和修改保存在当前页面的独立内存副本，关闭或刷新后不保留。页面持续显示这一边界，有修改时结束试用或离开页面会提示保存。需要保留时，到「数据与备份」导出副本。

这里只读原始目录，不限制网页已有的制卡、复习等操作。目录写入、接受外部修改和文件监听继续由桌面版提供。

| 能力                                           | 在线版方向                                                                                          |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 卡片、阅读、搜索、内容渲染、导入导出、前端插件 | 继续复用现有实现，保留无需后端的操作                                                                |
| 本地工作目录                                   | 用户选择目录后只读打开，展示卡组、卡片、材料、媒体与已有学习记录                                    |
| SQLite 学习状态                                | 使用已有 `sql.js` WASM，在 Worker 内读取数据库副本，复用共享 Schema 和引用校验                      |
| 试用中的编辑、评分和阅读进度                   | 写入独立的浏览器副本，明确显示原库不变；不自动覆盖已有浏览器学习库                                  |
| 外部修改接受、目录写入、原生监听               | 使用桌面版                                                                                          |
| 本机插件、LeetCode 联网判题、MCP stdio         | 仍为桌面能力；网页可读取已有练习、完整代码和结果，支持前端插件，不增加在线登录、联网判题或 MCP 服务 |

### 读取方式与实现边界

- 优先使用 `showDirectoryPicker({ mode: 'read' })`；不可用时使用目录文件选择，支持选择器的浏览器也可手动改用这一方式。检查实际选中的文件是否齐全；浏览器或系统遗漏隐藏的 `.repeaty` 时提示重新选择完整目录。
- 支持正式格式 3 的完整目录快照。检查 `workspace.json`、SQLite 身份与内部结构版本、记录关系及已接受正文的摘要和身份，按数据库映射读取内容；尚未接受的外部编辑不会直接用于复习。
- 首批支持关闭桌面学习库后直接选择完整目录，在浏览器内读取快照，无需先转换或导出。非空 WAL、未完成的正文发布、读取期间变化或缺少必要文件时，提示关闭学习库后重新读取；不忽略 WAL 后声称读到了最新进度，也不在浏览器中修复原库。反复读取相同摘要不能证明并发目录具有一致性。
- 复用 Anki 导入器已有的 `sql.js` 依赖，在 Worker 中以 `query_only` 方式读取内存数据库，不执行原生 `Library::open`、建表、迁移、写锁或检查点保存。读到不兼容格式时停止，不转换原目录。
- 目录枚举、SQLite 查询、内容校验和大正文解析放到 Worker。媒体按需读取并检查内容摘要，已有代码先加载摘要，展开或导出时分批读取正文。评分保存不扫描目录或读取无关代码。SQLite WASM 按需加载；共享 TypeScript 调度和渲染沿用现有实现。
- 当前读取上限：10 万个所选文件、256 MiB SQLite、32 MiB 已接受 Markdown；单份正文和媒体继续遵循目录及共享模型的大小限制。超限时保留当前学习库，并提示使用桌面版。
- 切换、关闭或重新选择目录时隔离会话，释放 Worker、文件引用及媒体 URL。明确显示哪些进度属于浏览器试用副本，哪些是原目录中的既有记录；原始目录的任何文件和字节均不得改变。

### 验证范围

1. 选择真实桌面目录后，卡组与卡片数量、到期状态、材料版本、已有评分及图片 / 音频与桌面一致；使用已接受版本，不把待接受文件直接用于复习。
2. 从该副本完成翻面、评分、撤销和阅读；浏览器副本与原目录隔离，关闭后原目录的文件集合与摘要不变，已有网页学习库不被覆盖。
