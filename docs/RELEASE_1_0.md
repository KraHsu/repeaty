## 兼容与回退

当前格式为 Library / JSON v13、IndexedDB v16、SQLite v10、API v11、`.repeaty` v10。新阅读反馈沿用材料记录表；旧库不补写反馈。桌面、账户服务与对应前端需一起升级。

升级前导出完整备份；账户服务另备份数据目录。回退使用升级前的数据目录或备份，不能让旧客户端直接写入新库。纯前端离线用户在准备好后主动刷新更新；不在复习中强制重载。

## 已知边界

阅读自适应使用显式理解反馈与经过天数，是有上下限的阅读安排规则；不声称测得记忆保持率。混合轮次不跨重启恢复，已保存的安排与评分保留。MCP 只访问桌面本地库，每次运行仍需主动开启和分享。草稿在本机持久保存，尚未确认的草稿不进入学习库备份。

Anki 进度与复杂模板、图片遮挡、个人 FSRS 参数训练、自动跨端同步不包含在 v1.0。桌面 LeetCode 仍依赖其网页接口，判题登录与请求在本机执行。Windows / macOS 安装包尚未配置代码签名或 Apple 公证。

本文件中未勾选的事项是发布前待办，不能据此宣称正式版已经就绪。
