# LeetCode 插件

[返回使用指南](USAGE.md) · [在线使用](https://www.krahsu.top/repeaty/)

将 LeetCode 题目加入卡组，在 Repeaty 编写代码并提交给 LeetCode 判题，按 FSRS 安排下一次复习。默认使用中国站 `leetcode.cn`，也可选择国际站 `leetcode.com`。两个站点的登录信息分别配置。本插件只在带后端版提供；GitHub Pages 不部署它。

## 配置与启用

1. 按[后端部署说明](SELF_HOSTING.md)启动 Rust 服务。默认已安装并启用 LeetCode，也可以在部署时通过 `REPEATY_PLUGINS` 关闭。
2. 部署者在所选 LeetCode 站点登录，在浏览器开发者工具的站点 Cookie 中找到 `LEETCODE_SESSION` 与 `csrftoken`。将值配置到服务环境变量：
   - 中国站：`LEETCODE_CN_SESSION`、`LEETCODE_CN_CSRF`。
   - 国际站：`LEETCODE_COM_SESSION`、`LEETCODE_COM_CSRF`。
3. 重启服务，在 Repeaty「插件」中开启 LeetCode。页面分别显示中国站和国际站的「判题配置」，点击「刷新状态」重新读取。读取公开题目通常不需要登录，提交判题需要配置有效的两个值。

“打开力扣网站”只是外部链接。在力扣网页登录不会自动连接 Repeaty；浏览器的登录信息不会传给后端。「已配置登录信息」表示服务已有配置，不代表会话仍有效，提交时才会验证。

登录信息只保存在部署环境，不填入网页、不放入 `VITE_*` 变量，也不进入 SQLite 学习库或学习备份。会话过期或站点要求验证时，先在 LeetCode 完成验证，再更新服务配置。不要将这些值提交到 Git。

**提交使用部署者配置的 LeetCode 账号，会进入该账号的正式提交记录。** 当前后端是个人使用的单学习库服务，不是多人判题平台；共享访问密钥就意味着允许使用这个学习库和判题账号。无需安装浏览器扩展，也无需保持 LeetCode 标签页打开。

关闭网页中的插件开关只影响当前浏览器，保留题目、草稿和复习进度；关闭后不进入复习队列。部署者设 `REPEATY_PLUGINS=''` 并重启服务，则所有客户端都无法调用该插件 API。

## 添加与复习

1. 创建卡组，点击「添加卡片」，再点击「添加 LeetCode 题目」，或选择「插件题目 → LeetCode」。
2. 选择站点，输入题目链接或英文标识，例如 `two-sum`，点击「读取题目」。完整链接中的站点优先于下拉选择；后续新题沿用最近成功读取或手选的站点。
3. 可填写「解题笔记」，保存思路、复杂度分析或参考代码，然后保存卡片。
4. 复习时选择编程语言，编辑代码，点击「提交到 LeetCode」。这会进行正式判题，而非仅运行示例测试。
5. 查看判题结果。未通过可修改代码再次提交；点击「结束作答并查看答案」显示解题笔记，再保存评分。

每张题目保留自己的站点和原始 Easy / Medium / Hard 难度。代码草稿按语言分别保存，未完成的作答会在刷新后恢复；已取得提交编号时，恢复后继续查询同一次提交，不自动重复提交。题面是读取时的快照，可通过编辑卡片重新读取。暂不自动导入 LeetCode 题解；参考答案由自己的解题笔记提供。

## 评分

手动评分和自动评分都使用 Repeaty 的「重来 / 困难 / 良好 / 简单」四档，影响下次复习时间，不修改 LeetCode 原始题目难度。判题未通过时只能选择「重来」。提前查看答案后，即使随后通过，本轮也记为「重来」。

自动评分的基础用时：

| 原始难度 | 基础用时 T |
| -------- | ---------- |
| Easy     | 10 分钟    |
| Medium   | 20 分钟    |
| Hard     | 35 分钟    |

| 判题与作答情况                                 | 自动评分 |
| ---------------------------------------------- | -------- |
| 未通过，或通过前查看答案                       | 重来     |
| 通过，1 次提交，用时 ≤ T                       | 简单     |
| 通过，至多 2 次提交，用时 ≤ 2T，且不满足上一档 | 良好     |
| 其余通过情况                                   | 困难     |

这是可解释的启发式规则，不是 LeetCode 官方评分或训练得到的 FSRS 参数。选择自动评分后仍需点击「保存评分」；通过后也可切回手动评分。

尝试次数只统计收到提交编号的正式提交，编译错误等正式判题失败也计入。用时统计 Repeaty 可见时的作答时间，可手动暂停；查询判题期间、切换标签页、通过后或查看答案后暂停。若提交请求中断、未收到编号，实际提交次数可能不完整，本轮停用自动评分；先在 LeetCode 检查提交记录，再决定是否重新提交。

保存后的复习记录包含次数、用时、结果、提交编号及评分方式，随备份和快照保存。「只练习」仍不写正式评分。撤销评分只撤销 Repeaty 记录，不能撤回 LeetCode 提交。

## 数据和连接限制

- 题面、代码模板和解题笔记保存在 SQLite，随 `.repeaty` / JSON 备份保存。题面中的图片只允许 LeetCode 图片域名，仍需网络，不作为本地附件备份。
- 未完成的代码草稿使用独立 IndexedDB 保存，评分后清理，不包含在备份中。需要长期保存的代码请写入解题笔记。
- 提交与查询需要 Repeaty 后端可以连接 LeetCode。仅使用 LeetCode 返回的正式结果；网络错误、限流、登录过期或服务内部错误不会当作答案错误。
- 服务不绕过登录、验证码或会员权限。遇到权限提示，在 LeetCode 页面完成登录或验证后重试；没有代码模板的题目暂不支持站内提交。
- 已有提交编号但查询失败时，点击「继续查询结果」。查询多次仍未结束时会暂停轮询，保留编号与草稿。
- 接入的是 LeetCode 网页接口，站点更改接口后可能需要更新服务。自动测试使用受控响应，不向真实账号提交代码。

将备份导入纯前端版时，LeetCode 题目及进度仍会保留并可再次导出，但不会进入复习队列。恢复到启用该插件的后端版即可继续使用。
