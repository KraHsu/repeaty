# LeetCode 插件

[返回使用指南](USAGE.md) · [在线使用](https://www.krahsu.top/repeaty/)

将 LeetCode 题目加入卡组，在 Repeaty 编写代码并提交给 LeetCode 判题，按 FSRS 安排下一次复习。默认使用中国站 `leetcode.cn`，也可选择国际站 `leetcode.com`。两个站点的登录信息分别配置。本插件只在桌面版提供；GitHub Pages 和开源后端均不部署它。

## 配置与启用

1. 安装或构建[桌面版](DESKTOP.md)，在「插件」中确认 LeetCode 已开启。
2. 在所选 LeetCode 站点登录，打开浏览器开发者工具 → **应用（Application）或存储（Storage）→ Cookie**，复制 `LEETCODE_SESSION` 与 `csrftoken` 的值。
3. 在 Repeaty **插件 → LeetCode** 中找到对应站点，填写两个值，点击 **保存登录信息**。保存立即生效，重启后保留。

只填写 Cookie 值，不含名称或整段 Cookie。保存后输入框清空，不会回显已有凭据；会话过期时重新填写。清除某个站点的配置不影响另一站点。

「打开力扣网站」会在系统浏览器打开链接，不会自动连接 Repeaty。「已配置登录信息」表示本机保存成功，提交时才会验证会话是否有效。

Cookie 通过 Tauri IPC 写入本机独立的 `leetcode.credentials.sqlite3`，Unix 权限为 `0600`。桌面 Rust 客户端直接访问力扣，不将凭据发送到 Repeaty 上游服务，也不写入卡组导出。文件未加密，本机管理员仍能读取，因此应使用可信安装包、插件和操作系统。

**提交会使用该 Cookie 所属账号，在 LeetCode 留下正式提交记录。** 不需要浏览器扩展，也不需要一直打开力扣标签页。桌面版不读取服务器端 `LEETCODE_*` 环境变量。

关闭插件会保留题目、草稿和进度，并从复习队列中排除该题型。需要移除已保存的 Cookie 时，应先点击「清除登录信息」。

## 添加与复习

1. 创建卡组，点击「添加卡片」，再点击「添加 LeetCode 题目」，或选择「插件题目 → LeetCode」。
2. 选择站点，输入题目链接或英文标识，例如 `two-sum`，点击「读取题目」。完整链接中的站点优先于下拉选择；后续新题沿用最近成功读取或手选的站点。
3. 可填写「解题笔记」，保存思路、复杂度分析或参考代码，然后保存卡片。
4. 复习时选择编程语言，编辑代码，点击「提交到 LeetCode」。这会进行正式判题，而非仅运行示例测试。
5. 查看判题结果。未通过可修改代码再次提交；点击「结束作答并查看答案」显示解题笔记，再保存评分。

每张题目保留自己的站点和原始 Easy / Medium / Hard 难度。代码草稿按语言分别保存，未完成的作答会在刷新后恢复；已取得提交编号时，恢复后继续查询同一次提交，不自动重复提交。题面是读取时的快照，可通过编辑卡片重新读取。暂不自动导入 LeetCode 题解；参考答案由自己的解题笔记提供。

## 评分

手动评分和自动评分都使用 Repeaty 的「重来 / 困难 / 良好 / 简单」四档，影响下次复习时间，不修改 LeetCode 原始题目难度。判题未通过时只能选择「重来」。提前查看答案后，即使随后通过，本轮也记为「重来」。

自动评分的基础用时：

| 原始难度 | 基础用时 T |
| -------- | ---------- |
| Easy     | 10 分钟    |
| Medium   | 20 分钟    |
| Hard     | 35 分钟    |

| 判题与作答情况                                 | 自动评分 |
| ---------------------------------------------- | -------- |
| 未通过，或通过前查看答案                       | 重来     |
| 通过，1 次提交，用时 ≤ T                       | 简单     |
| 通过，至多 2 次提交，用时 ≤ 2T，且不满足上一档 | 良好     |
| 其余通过情况                                   | 困难     |

这是可解释的启发式规则，不是 LeetCode 官方评分或训练得到的 FSRS 参数。选择自动评分后仍需点击「保存评分」；通过后也可切回手动评分。

尝试次数只统计收到提交编号的正式提交，编译错误等正式判题失败也计入。用时统计 Repeaty 可见时的作答时间，可手动暂停；查询判题期间、切换标签页、通过后或查看答案后暂停。若提交请求中断、未收到编号，实际提交次数可能不完整，本轮停用自动评分；先在 LeetCode 检查提交记录，再决定是否重新提交。

保存后的复习记录包含次数、用时、结果、提交编号及评分方式，随备份和快照保存。「只练习」仍不写正式评分。撤销评分只撤销 Repeaty 记录，不能撤回 LeetCode 提交。

## 数据和连接限制

- 题面、代码模板和解题笔记保存在当前学习库，随 `.repeaty` / JSON 备份保存。题面中的图片只允许 LeetCode 图片域名，仍需网络，不作为本地附件备份。
- 未完成的代码草稿使用独立 IndexedDB 保存，评分后清理，不包含在备份中。需要长期保存的代码请写入解题笔记。
- 提交与查询需要 此设备可以连接 LeetCode。仅使用 LeetCode 返回的正式结果；网络错误、限流、登录过期或服务内部错误不会当作答案错误。
- 插件不绕过登录、验证码或会员权限。遇到权限提示，在 LeetCode 页面完成登录或验证后重试；没有代码模板的题目暂不支持站内提交。
- 已有提交编号但查询失败时，点击「继续查询结果」。查询多次仍未结束时会暂停轮询，保留编号与草稿。
- 接入的是 LeetCode 网页接口，站点更改接口后可能需要更新桌面插件。自动测试使用受控响应，不向真实账号提交代码。

将备份导入网页版本时，LeetCode 题目及进度仍会保留并可再次导出，但不会进入复习队列。恢复到启用该插件的桌面版即可继续使用。
