# LeetCode 插件

[返回使用指南](USAGE.md) · [在线使用](https://www.krahsu.top/repeaty/)

将 LeetCode 题目加入卡组，在 Repeaty 编写代码并提交给 LeetCode 判题，按 FSRS 安排下一次复习。默认使用中国站 `leetcode.cn`，也可选择国际站 `leetcode.com`。两个站点需要分别登录。

## 安装连接扩展

1. 在添加卡片的 LeetCode 表单或复习页展开「连接 LeetCode」，下载并解压扩展。
2. 桌面 Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的目录。
3. 在同一浏览器另开一个标签页，打开所选 LeetCode 站点并登录，保留该标签页。
4. 刷新 Repeaty。

扩展没有上架商店；更新扩展时重新下载解压，再在扩展管理页点击重新加载。本地开发先执行 `npm run build`，直接加载生成的 `dist-connector/`。

Repeaty 仍是静态网页，无需部署后端。扩展在 LeetCode 标签页内发出请求，登录信息不会传给 Repeaty，不需要填写账号密码或复制 Cookie。提交会出现在自己的 LeetCode 提交记录中。手机上仍可查看已保存题目与笔记，但本版判题连接器需要能加载该扩展的桌面 Chrome / Edge。

## 添加与复习

1. 创建卡组，点击「添加卡片」，选择「插件题目 → LeetCode」。
2. 选择站点，输入题目链接或英文标识，例如 `two-sum`，点击「读取题目」。完整链接中的站点优先于下拉选择；后续新题沿用最近成功读取或手选的站点。
3. 可填写「解题笔记」，保存思路、复杂度分析或参考代码，然后保存卡片。
4. 复习时选择编程语言，编辑代码，点击「提交到 LeetCode」。这会进行正式判题，而非仅运行示例测试。
5. 查看判题结果。未通过可修改代码再次提交；点击「结束作答并查看答案」显示解题笔记，再保存评分。

每张题目保留自己的站点和原始 Easy / Medium / Hard 难度。代码草稿按语言分别保存，未完成的作答会在刷新后恢复；已取得提交编号时，恢复后继续查询同一次提交，不自动重复提交。题面是读取时的快照，可通过编辑卡片重新读取。暂不自动导入 LeetCode 题解；参考答案由自己的解题笔记提供。

## 评分

手动评分和自动评分都使用 Repeaty 的「重来 / 困难 / 良好 / 简单」四档，影响下次复习时间，不修改 LeetCode 原始题目难度。判题未通过时只能选择「重来」。提前查看答案后，即使随后通过，本轮也记为「重来」。

自动评分的基础用时：

| 原始难度 | 基础用时 T |
| -------- | ---------- |
| Easy     | 10 分钟    |
| Medium   | 20 分钟    |
| Hard     | 35 分钟    |

| 判题与作答情况                                 | 自动评分 |
| ---------------------------------------------- | -------- |
| 未通过，或通过前查看答案                       | 重来     |
| 通过，1 次提交，用时 ≤ T                       | 简单     |
| 通过，至多 2 次提交，用时 ≤ 2T，且不满足上一档 | 良好     |
| 其余通过情况                                   | 困难     |

这是可解释的启发式规则，不是 LeetCode 官方评分或训练得到的 FSRS 参数。选择自动评分后仍需点击「保存评分」；通过后也可切回手动评分。

尝试次数只统计收到提交编号的正式提交，编译错误等正式判题失败也计入。用时统计 Repeaty 可见时的作答时间，可手动暂停；查询判题期间、切换标签页、通过后或查看答案后暂停。若提交请求中断、未收到编号，实际提交次数可能不完整，本轮停用自动评分；先在 LeetCode 检查提交记录，再决定是否重新提交。

保存后的复习记录包含次数、用时、结果、提交编号及评分方式，随备份和快照保存。「只练习」仍不写正式评分。撤销评分只撤销 Repeaty 记录，不能撤回 LeetCode 提交。

## 数据和连接限制

- 题面、代码模板和解题笔记保存在本地，随 `.repeaty` / JSON 备份保存。题面中的图片只允许 LeetCode 图片域名，仍需网络，不作为本地附件备份。
- 未完成的代码草稿使用独立 IndexedDB 保存，评分后清理，不包含在备份中。需要长期保存的代码请写入解题笔记。
- 提交与查询需要联网、扩展和打开的 LeetCode 标签页。仅使用 LeetCode 返回的正式结果；网络错误、限流、登录过期或服务内部错误不会当作答案错误。
- 连接器不绕过登录、验证码或会员权限。遇到权限提示，在 LeetCode 页面完成登录或验证后重试；没有代码模板的题目暂不支持站内提交。
- 已有提交编号但查询失败时，点击「继续查询结果」。查询多次仍未结束时会暂停轮询，保留编号与草稿。
- 接入的是 LeetCode 网页接口，站点更改接口后可能需要更新扩展。自动测试使用受控响应，不向真实账号提交代码。

其他域名的自行部署见[开发文档](DEVELOPMENT.md#题目插件)。
