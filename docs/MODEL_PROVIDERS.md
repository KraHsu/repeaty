# 模型连接

[返回首页](../README.md) · [插件开发](PLUGINS.md) · [MCP 与 CLI](MCP.md)

桌面宿主提供通用模型连接，官方助手和第三方插件通过同一套公开接口使用。模型连接与学习库自动化是两种权限：连接模型不代表可以读取学习库，更不代表可以修改材料。

## OpenAI 兼容 API

建立 `openai-compatible` 配置，填写服务的 Base URL、模型名称和可选 API 密钥。协议使用 `/models` 检查连接与列出模型，使用 `/chat/completions` 的 SSE 流式接口发送文本、图片及函数工具。

远程地址必须为 HTTPS；明确的 `localhost`、`127.0.0.1` 和 `::1` 本机服务允许 HTTP。地址不能夹带用户名、密码、查询参数或片段。连接不会跟随重定向，也不会把服务返回的原始错误正文当作提示展示。

“OpenAI 兼容”不保证所有服务都实现相同功能。连接检查只验证模型列表接口，不会消费推理额度；工具和图片能力在没有实际使用证据时标记为未知。服务拒绝图片、工具或 SSE 时会显示错误，不会悄悄删除这些输入重新请求。

## 原生 Codex

`codex` 配置启动本机原生 Codex 可执行文件的 app-server。可指定绝对路径，也可使用支持的安装位置自动查找。宿主不运行 npm 的 JavaScript 启动器，不要求系统安装 Node.js，不自动安装 Codex。

登录通过 Codex 提供的账号流程完成，不读取其他应用已有的登录凭据，也不假定 ChatGPT 订阅等同于 API 密钥。账号可用模型由 Codex 返回；是否支持登录、模型及额度以当前账号和 Codex 服务为准。[官方 app-server 协议](https://developers.openai.com/codex/app-server/)

每份配置使用 Repeaty 设备目录中的独立 Codex home 和隔离工作目录。宿主关闭内置终端、文件编辑、浏览器、连接器、MCP、技能发现等能力，只接受本轮明确注册的 Repeaty 动态工具。非声明工具、其他会话的回调和越过工作目录作用域的响应会被拒绝。动态工具是 Codex 的实验协议；不兼容的原生版本会明确报错，不降级为不受控的命令执行。[动态工具协议](https://developers.openai.com/codex/app-server/)

当前原生 Codex 仍会在工具目录中声明仅用于 Plan 模式的 `request_user_input`。Repeaty 固定使用 Default 模式，并拒绝该工具及所有非声明动态工具的服务端调用；它不提供访问终端或文件的通道。工具目录的这项上游限制与实际可执行权限分别验证。

## 数据与生命周期

API 密钥保存在设备上的私有凭据存储，模型配置的公开列表只返回是否已保存密钥；密钥不进入学习库、插件设置、导出包或流式事件。修改服务地址时，不自动把旧密钥转交给新地址。Codex 的独立登录状态也保留在设备目录中。

删除模型配置会结束相关请求；Codex 配置会等待对应子进程退出，再移除该配置的登录文件与会话归属记录。编辑配置不会自动删除登录状态。

调用模型会把请求中选择的文本、图片、上下文与工具结果发给所选服务。库内的聊天内容、草稿及授权范围由使用连接的插件管理，设备凭据不随学习目录移动。删除或关闭插件不删除学习记录。

每次请求绑定当前学习库、插件及本次启用实例。停止、卸载、切换学习库或取消会结束相应请求；模型连接失败和取消仍保留已经收到的文本供界面恢复。单次输入最多 16 MiB，包含最多三张 PNG/JPEG/WebP 图片，每张解码后最多 3 MiB；输出、工具参数和事件队列也有上限。

## 插件接口

插件需要在包的 `permissions` 中声明 `models: true`，并由用户信任当前包。完整类型见 [providers.d.ts](../packages/plugin-api/providers.d.ts)。接口通过宿主的 `nativePlugin` 提供，不暴露 Rust、Node.js 或任意子进程调用能力。

| 操作                                   | 用途                                   |
| -------------------------------------- | -------------------------------------- |
| `model.profiles.list/save/remove/test` | 管理设备配置、检查连接及模型列表       |
| `model.account.login/logout`           | 原生 Codex 账号登录和退出              |
| `model.stream.start/poll/cancel`       | 启动请求、按 cursor 读取增量事件、取消 |
| `model.stream.respond`                 | 回答当前 Codex 请求中的动态工具回调    |
| `model.dispose`                        | 结束当前插件启用实例的请求与原生连接   |

插件不得把模型输出或材料中的指令当作新的用户授权。写入学习库应走公开自动化的授权、预览和应用接口；宿主统一处理修订号、回执、恢复点与资源清理。
