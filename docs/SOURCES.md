# 学习材料与摘录制卡

[使用指南](USAGE.md) · [返回首页](../README.md)

在「学习材料」中点击「导入材料」，选择文本 / Markdown 文件，或直接粘贴正文。填写标题；有原始网页时，可以附上链接。保存后，原文快照进入当前学习库，不需要连接原网站才能阅读。

静态版、账户版和桌面版使用相同流程。桌面连接上游时，材料保存到当前登录的账户库；切回本地库后，两边的材料分别保留。

## 继续阅读

滚动原文或 Markdown 预览后，停留片刻会自动保存位置。列表显示上次阅读时间，点击「继续阅读」回到保存处；重新打开「学习材料」时，默认在待阅读列表中打开最近保存位置的材料。窗口宽度改变后，按文本位置恢复，可能与原先相差一行。

「保存阅读位置」立即保存当前位置，「从头阅读」回到开头。切换原文与预览时也会记录阅读位置和显示方式。关闭页面或退出应用前，确认看到「阅读位置已保存」；若仍在保存，最后一次移动可能尚未写入。保存失败会保留本次待保存位置，显示错误与重试按钮，关闭页面前可重试。

阅读位置属于当前学习库，随完整备份和操作快照保留。静态版和桌面本地库可离线保存；账户版及桌面上游模式需要连接服务，切换库后各自保留。阅读不会修改卡片、复习记录或 FSRS 状态。

## 阅读队列

「学习材料」提供待阅读、稍后阅读、已归档和全部材料四个列表。新导入的材料和旧版本中的材料默认进入待阅读。待阅读先按高、普通、低优先级排列，同档再按安排日期和导入时间排序；没有安排时使用导入日期。稍后阅读与归档维持日期顺序，全部材料依次列出这三组。阅读和保存位置不会改变排序。

- **阅读优先级**：在阅读器中选择高、普通或低，默认普通。更改后保留日期和位置；筛选条件仍包含当前材料时继续显示，已不匹配时从列表中移除。高优先级不会让稍后阅读提前到期，也不会恢复归档材料。
- **稍后阅读**：点选「明天」「3 天后」「1 周后」，或填写下次阅读日期，默认为明天。快捷选项显示实际日期，选择或输入后，点击「保存阅读安排」才会生效；取消不会改变原安排。保存后移到稍后阅读列表，到指定日期自动回到待阅读。日期按当前设备的本机时区和日历计算。
- **归档材料**：从待阅读中收起，原文、阅读位置、摘录和关联卡片继续保留。归档后卡片仍按原来的 FSRS 安排复习。
- **加入待阅读**：从稍后阅读或归档中移回今天的待阅读列表，保留原先的阅读位置。

更改优先级或安排时，当前已显示的阅读位置与设置在同一事务中保存；保存失败会保留原状态和错误提示，可以重试。操作前快照与完整备份包含阅读安排和优先级。归档与删除的区别是：归档保留原文与出处，删除会解除关联。

快捷安排适用于原文和独立摘录，各自保存日期。在阅读轮次中，保存成功后继续下一篇；失败时保留选中的日期和当前篇，重试不会提前跳过材料。它是手动选择阅读日期，不会根据阅读次数自动延长间隔。

队列按日期运行，不自动判断材料是否掌握。嵌套片段、自适应间隔、PDF 和网页抓取留待后续需求；设计参考见 [Foliole 阅读笔记](READING_REFERENCES.md)。

## 递增阅读间隔

读过一段后，点击「读过，安排下次」。弹窗会显示本次间隔和实际日期，点击「保存阅读安排」后生效。间隔依次为 **1 → 3 → 7 → 14 → 30 天**，之后保持 30 天，按本机日历计算。阅读轮次中保存成功会继续下一篇；保存失败保留当前篇，可以重试。

每篇原文和独立摘录分别记录上次间隔；新摘录从 1 天开始。打开材料、滚动、普通「下一篇」和取消弹窗都不会推进阶梯。使用「稍后阅读」自选日期、调整优先级、归档或加入待阅读时，上次间隔继续保留。归档期间收起「读过，安排下次」，恢复后可以接着安排。

「重置间隔」让下一次从 1 天开始，已安排的阅读日期保持不变，确认前可以取消。间隔随学习库、快照和完整备份保留，刷新或退出重开后继续。它用于安排再次阅读，与卡片的 FSRS 评分分别处理。

## 筛选材料

标题搜索、材料类型（全部 / 原文 / 摘录）与优先级可以组合使用，四个队列的数量会随筛选更新。未设置类型的旧材料按原文处理，未设置优先级时按普通处理；原文已删除的独立摘录仍属于摘录。搜索只匹配标题，不读取所有正文。

「阅读筛选结果」从当前列表的全部分页中选取待阅读材料。例如选择「摘录＋高优先级」，可以集中读完这一批。全部材料中的未来安排与归档内容不会加入本轮；稍后阅读、已归档列表及没有匹配项时，该按钮不可用。旁边显示当前列表总数和可阅读数量。

「清除筛选」恢复全部类型、全部优先级与空搜索词，保留当前队列。修改筛选条件会回到第一页。筛选只保留在本次材料页面中，刷新、离开页面或切库后恢复默认。

从原文列表点击「打开摘录」时会清除筛选并切到全部材料，保证目标可见；新导入材料或保存独立摘录后也会清除筛选。轮次中的摘录弹窗保持原来的阅读范围。

## 连续阅读一轮

「开始一轮阅读」读取全部待阅读材料，不受列表筛选影响；「阅读筛选结果」只读取符合条件的待阅读材料。两种入口都先保存当前位置，再按优先级和日期固定本轮顺序。轮次中收起列表和筛选，筛选阅读会显示使用的范围；需要自行选材料时，点击「结束本轮」返回。

筛选轮次结束后，「再读一轮」继续使用相同条件，从当时的待阅读中重新选择；本轮中改为其他优先级的材料可能不再符合下一轮条件。返回材料列表后仍保留开始时的筛选，可调整或清除。

- **下一篇**：先保存当前阅读位置，再进入下一篇。最后一篇显示「完成本轮」，保存后到达结束页面。
- **稍后阅读 / 归档材料**：保留位置，保存安排后进入本轮下一篇。
- **结束本轮**：保存当前位置，回到材料列表；保存失败时停留在原篇，可重试。正文未能读取时也可直接结束，原位置保留。

每篇材料本轮最多出现一次。顺序在开始时固定，优先级调整留到下一轮生效；新导入、保存为摘录或后来到期的材料也留到下一轮。已删除、换了快照或不再待阅读的材料会跳过。

离开材料页、刷新或退出应用后，本轮结束，每篇材料已保存的位置继续保留。再次开始时按当前队列重新排列；轮次本身不进入备份。阅读到末尾不代表已经掌握，也不会产生 FSRS 评分。

## 保存独立摘录

在原文输入区选中文字，点击「保存为摘录」，填写标题后保存。无需先创建卡组或卡片。摘录正文保持选区原样，加入待阅读列表，并带有「摘录」标记；可以单独设置阅读优先级、稍后阅读或归档，位置也单独保存。新摘录默认普通优先级，不继承原材料的安排。

点击「查看出处」回到原文并高亮实际选区。同一段文字出现多次时，也能定位到选中的那一次。摘录保存独立正文；原文被删除后仍可阅读和制卡，页面会提示出处已解除。

当前支持从原材料保存一级摘录，每次最多 10000 个字符。摘录可以选取更小的部分制卡，暂不支持继续提取为嵌套摘录。

## 在原文中查找摘录

打开原材料后，「本篇摘录」按选区在原文中的位置排列，显示标题、正文预览和关联卡片数；稍后阅读及已归档的摘录也会列出。每页五条。关联卡片数包含双向、多个挖空生成的卡片及暂停卡，不代表当前到期数量。

- **定位原文**：切回原始文本，选中实际范围并滚动到选区开头，也支持键盘操作。当前位置照常自动保存。
- **打开摘录**：先保存原文位置，再进入该摘录的独立阅读器。会切到全部材料以显示目标，保留摘录原有的日期和归档状态。保存失败时留在原页，可重试。
- **查看已有摘录**：再次选中相同范围时会出现提示，点击跳到对应列表页。相同文字出现在其他位置时不会混为同一段；仍可主动保存另一份。

阅读轮次中打开摘录会使用弹窗，关闭后继续原篇，顺序不变。列表与匹配不额外读取全部摘录正文；只有打开时才读取对应正文。删除摘录或恢复备份后，列表和卡片数随当前库更新。

## 从摘录创建卡片

1. 打开一篇材料，在原文输入区选中文字，点击「用摘录制卡」；已保存的摘录可直接点击「用此摘录制卡」。
2. 摘录会填入答案，在编辑器中填写问题；可以修改答案，也可以改为双向或挖空笔记。
3. 保存卡片。它使用所选卡组的正常复习规则，材料不会直接产生 FSRS 评分。

Markdown 可以切换阅读预览；选取摘录时切回原文，选取位置对应保存的文本。相同文字在原文中出现多次时，记录本次实际选取的位置。列表中的「关联笔记」可以打开已保存的卡片。

复习显示答案后，点击「查看原文」打开快照。摘录处会高亮，页面定位到该位置。由独立摘录制作的卡片先显示摘录，点击「查看出处」可以再看原文；局部选区会定位到原文的对应位置。查看材料不会额外评分；关闭原文后继续按实际表现评分。

桌面本地库另有「通过 MCP 制卡」：选中摘录后主动分享给客户端，接收问答、双向或挖空卡草稿，在编辑器中核对并确认保存。草稿保存在本机，未完成的编辑可「保存草稿」后下次继续；分享授权不会恢复。草稿不进入备份，确认后的出处和普通摘录卡相同。[配置、限制与重试](MCP.md#从摘录生成草稿)

## 快照与外部文件

每次导入都会创建独立快照，标题或链接相同也不会覆盖旧材料。外部文件或网页发生变化时，旧卡片继续引用原先的快照。当前不自动抓取网页、监听文件更新或合并来源版本。

导入内容以 UTF-8 保存，去除开头的 BOM，换行统一为 LF，保证各平台的选取位置一致。Markdown 沿用卡片的显示方式：不执行 HTML 或脚本，不下载外部图片和音频。文件引用的外部附件不包含在材料快照中。

第一版支持 `.txt`、`.md`、`.markdown`，每份材料最大 **1 MiB**、**250000 个 UTF-16 代码单元**；每条摘录最多 **10000 个代码单元**。普通中文、英文字符各计一个，部分 emoji 占两个。原材料与独立摘录合计最多 **10000 份**。PDF、网页抓取、图片 OCR 和附件目录导入暂不包含在本版。

## 导出、删除与恢复

「导出原文」下载保存的 UTF-8 文本 / Markdown 快照，不包含关联卡片及复习进度。需要迁移整个学习库时，使用「数据与备份」中的 `.repeaty` 完整备份，它包含材料、原文快照、阅读位置、阅读安排、递增间隔、优先级、摘录位置、卡片、媒体和进度；JSON 备份也支持，但仍受 100 MB 上限限制。

删除原材料时，会解除直接引用它的笔记和摘录的出处关联，已有独立摘录与卡片仍保留。删除独立摘录会解除关联笔记的来源，笔记内容、卡片与复习进度保留。删除卡片不会自动删除材料。

操作前会保存快照，可在「数据与备份」中恢复原文、摘录和出处。恢复完整备份或快照会替换整个当前学习库。

原文缺失、损坏或无法读取时会显示错误，不会从外部链接重新下载一份代替。可尝试重读或从完整备份恢复。
