# 学习材料与摘录制卡

[使用指南](USAGE.md) · [返回首页](../README.md)

在「学习材料」中点击「导入材料」，选择文本 / Markdown 文件，或直接粘贴正文。填写标题；有原始网页时，可以附上链接。保存后，原文快照进入当前学习库，不需要连接原网站才能阅读。

桌面版将材料保存在当前工作目录，可离线阅读和制卡。在线版使用浏览器学习库，也可只读打开用户选择的工作目录；试用中的编辑和评分保存在独立副本，不写回原目录。[在线工作目录的范围](WORKSPACE_MODE.md#无后端在线工作目录)。

## 阅读工作区

左侧选择材料或浏览目录，中间阅读正文，右侧「上下文」查看链接、属性、批注、关联笔记和摘录。「上下文」可以收起；宽屏下可拖动分隔条调整左右两栏的宽度，聚焦分隔条后也可用方向键调整。较长的阅读预览与上下文各自滚动，窄窗口中各区域改为上下排列。阅读位置仍按材料保存。

Markdown 默认显示阅读预览；此前保存过原文视图的材料沿用原设置。「查看 Markdown 原文」切换到原始文本，「阅读 Markdown 预览」切回渲染结果。

## 在预览中选择文字

在预览中直接选中文字，即可「保存为摘录」「用摘录制卡」「制作挖空卡」或「添加批注」。选区记录的是这一版本的原文范围；相同段落重复出现时，引用仍指向选中的那一次。跨段落、列表、表格以及中英文、emoji 的选区均按原文位置处理。

摘录保存原文片段，因此可能带有加粗、链接或列表等 Markdown 标记，而不只是屏幕上的纯文字。HTML 块、公式内部等无法精确映射回原文的选区会提示切换原文视图，不会用相似文字猜测位置。需要选取这些内容时，切换后直接选择相应源码。

任务列表可在预览中勾选。勾选会保存新的正文版本，旧版本与关联摘录保留；它不会给卡片评分或改变阅读安排。

## 原位编辑正文与草稿

点击「编辑正文」，直接修改文本 / Markdown。「属性与来源」中可以同时修改标题、来源网址和自定义 YAML 属性。编辑器支持 Tab / Shift+Tab 缩进、回车延续列表，以及插入任务列表、代码块和公式；中文输入法选字期间不会触发这些编辑快捷操作。

输入会单独保存草稿。看到「草稿已保存」后，可以「保留草稿并返回」，下次继续；「放弃草稿」删除未提交的修改。桌面工作目录与普通浏览器学习库可跨重启恢复草稿；只读目录试用中的修改仅保留在当前页面会话。草稿尚未成为新的材料正文。

点击「保存为新版本」，或按 Ctrl / ⌘ + Enter，才会提交正文和属性，并消费对应草稿。正文修改产生不可变的新版本，从头阅读；材料身份、阅读安排、卡片调度与历史保留。旧摘录、批注和卡片出处继续引用原版本，可从「历史版本」查看。应用顶部的撤销 / 重做可恢复提交前后的内容。

若正文已在别处更新，编辑器会阻止旧草稿覆盖新版本。请先保留或复制草稿内容，再重新打开当前版本核对；程序不会自动合并两份正文。保存失败时输入仍在，处理错误后可重试。

## 目录与材料层级

在材料区切换到目录视图，可以新建文件夹，并通过菜单改名、移动、排序或删除。文件夹使用稳定身份，改名或移动不改变材料身份、阅读安排与摘录出处。删除文件夹会将其中内容移到上一级，保留材料。

这是学习库内的组织结构，不会把桌面 `sources/` 中的文件按同样层级移动。材料父子关系与「摘录来自哪一篇、哪一版、哪一段」分别保存；整理目录不会改写出处。

## 属性与展示字段

正文编辑器中的自定义属性使用 YAML 对象，无需填写 `---` 分隔线。例如：

```yaml
author: 作者
tags:
  - 阅读
  - 记忆
published: 2026
```

标题和来源网址使用专用字段，`repeaty` 为应用保留字段；这些字段不能在自定义属性中覆盖。未展示的自定义属性仍会保留，保存时会检查格式，不执行 YAML 自定义标签或别名。

在「设置 → 通用 → 阅读」的「材料属性」中，用逗号分隔填写要展示的字段，如 `author, tags, published`；留空显示所有自定义属性。这只影响上下文中的展示，不删除材料文件里的其他字段。

## Wiki 链接与反向链接

正文支持 `[[材料标题]]`。有多篇同名材料时，点击后由你选择目标；找不到目标时显示未找到，不会自动新建材料或跳转外站。鼠标悬停或键盘聚焦链接可查看目标预览。

「上下文」中的「链接与反向链接」显示本篇引用了哪些材料、哪些材料引用了本篇，也提供复制稳定链接。稳定格式为 `[[source:材料ID|显示文字]]`，即使目标改名仍能解析；普通标题链接则按当前标题匹配。代码里的类似文字不会作为 Wiki 链接。

## 全文检索与同义词

「搜索材料内容…」搜索当前已接受版本的标题和正文，与列表的标题筛选分开。多个条件用空格连接，要求同时匹配；完整词组用双引号包围。搜索结果提供正文片段，点击后打开对应材料。

全文索引由 Worker 按需建立，避免在界面线程解析整库。索引只是可重建的缓存；「重建检索索引」不会更改材料或学习记录，普通卡片评分也不会触发整库正文扫描。

在「设置 → 通用 → 搜索」配置「同义词组」，每行一组、逗号分隔，例如 `间隔重复, spaced repetition`。搜索时勾选「扩展同义词」即可匹配同组词语；它只扩展查询，不替换材料正文。插件注册检索提供方后，也可在搜索区选择使用。

## 批注

选中文字后点击「添加批注」，填写内容并保存。批注编辑面板可以移动和调整大小；右侧上下文集中列出本篇批注，方便边读边看。

批注绑定选中时的正文版本和原文范围。后来修改正文，不会把批注挪到新版本中相似的文字上；列表会标明来自历史版本，点击可查看当时的原文。批注编辑与正文草稿分别处理，离开前应保存批注，或确认放弃未保存内容。

## 格式清理插件

在「插件」页面安装并启用官方「格式清理」，侧栏会出现对应入口。在「设置 → 工具 → 格式清理」配置空白、空行、缩进和文字 / 正则替换规则，然后选择一篇文本或 Markdown 材料，点击「预览清理」，对比前后正文，再「应用清理」。

清理保护代码、链接地址、HTML 标签和 YAML 前置属性。应用结果保存为新的材料版本，可从顶部撤销 / 重做；停用或卸载插件不删除正文、版本或学习记录。插件不会自动批量清理整库，也不编辑 PDF 等格式的原件。[插件使用说明](../plugins/format-cleanup/README.md)。

## PDF、EPUB、HTML 与图像

在「插件 → 安装或更新官方插件」中分别安装 PDF 阅读器、EPUB 与 HTML 阅读、图像与公式遮挡，然后在「学习材料 → 插件导入」选择对应格式。插件独立更新，按学习库安装，停用或卸载仍保留材料、原件、卡片和学习记录。

- PDF 提供连续页面、页码、搜索、适宽、缩放旋转，以及跨栏和跨页的文字选区。选区沿用摘录、普通卡片和挖空操作；复习回源会高亮原版本中的对应区域。
- EPUB 保留目录、章节、本地资源和内部链接，可选自由或顺序阅读；顺序模式点击「完成本章」后释放下一章，操作可撤销。HTML 文件可配合用户选择的本地资源文件夹导入，活动内容被清理，远程资源不会自动下载。
- 图片可以缩放、旋转、框选、添加区域批注与导出裁切 PNG。图片和 Markdown 公式均可制作多区域遮挡题，每个区域独立复习。公式通过选择渲染后的文字元素创建选区。

移动或重命名遮挡区域保留卡片身份；退役后恢复区域会恢复原调度和完整历史。重新创建区域会生成新卡片。材料页面的「导出原件」保留导入文件原有字节；JSON 与 `.repeaty` 学习备份包含文档原件、资源、版本定位和退役记录，但不会隐式安装插件代码。

各格式的大小、页数、解压和选区限制，以及扫描件、加密书籍等边界，见 [PDF 阅读器](../plugins/pdf-reader/README.md)、[EPUB 与 HTML 阅读](../plugins/document-reader/README.md)和[图像与公式遮挡](../plugins/visual-occlusion/README.md)。当前开发分支已提供这些插件，既有发布安装包不代表已包含它们。

## 编辑材料信息

打开原文或独立摘录，点击「编辑材料信息」，修改标题或来源链接后保存。链接可以清空。取消或按 Esc 关闭时保留原信息；保存失败会保留输入，修复连接或存储问题后可重试。

修改只适用于这一篇材料。原文改名后，已有摘录的标题和链接仍保留各自的值；从此以后新保存的摘录采用当时的原文链接。摘录的出处位置不变，仍能定位原文中的同一段文字。原文已删除的独立摘录也能修改信息。

列表、搜索和「本篇摘录」使用新标题。若新标题不再匹配当前搜索，材料会从当前列表中移除；更换搜索词或清除筛选即可找到。在已经开始的阅读轮次中，改名后继续留在本篇，本轮顺序保持不变；下一轮重新应用筛选。

正文、快照编号、创建时间、阅读位置、日期、递增间隔、优先级与已有卡片进度都保留。有可用阅读位置时，会与信息一起保存。修改前的信息可从操作快照恢复，新信息随完整备份保留。另一页面已更新材料或学习库发生变化时，不会覆盖新的内容；刷新后重新打开编辑。

## 外部修改正文与附件

桌面版可在编辑器中修改 `sources/` 下的 Markdown，变化会自动列入「工作目录」，比较并确认后接受修改。新文件也可登记为材料。正文、格式或相对路径附件变化后保存新版本，新版从头阅读；旧版的位置保留，阅读安排和卡片进度不变。只改标题、链接或文件名会保留当前位置。

旧摘录、卡片出处和已接收的 AI 草稿继续绑定原快照。材料的「历史版本」可以查看旧正文；修改摘录自身后，原逐字版本和出处也会保留。将图片、音频放进 `assets/`，使用 `![图片](../assets/example.png)` 或 `<audio src="../assets/example.wav" controls></audio>`；接受时保存附件快照，外部替换同名文件不会改变旧版本。详细限制见[工作目录](WORKSPACE_MODE.md)。

## 继续阅读

滚动原文或 Markdown 预览后，停留片刻会自动保存位置。列表显示上次阅读时间，点击「继续阅读」回到保存处；重新打开「学习材料」时，默认在待阅读列表中打开最近保存位置的材料。窗口宽度改变后，按文本位置恢复，可能与原先相差一行。

「保存阅读位置」立即保存当前位置，「从头阅读」回到开头。切换原文与预览时也会记录阅读位置和显示方式。关闭页面或退出应用前，确认看到「阅读位置已保存」；若仍在保存，最后一次移动可能尚未写入。保存失败会保留本次待保存位置，显示错误与重试按钮，关闭页面前可重试。

阅读位置属于当前工作目录，随完整备份和操作快照保留，可离线保存。阅读不会修改卡片、复习记录或 FSRS 状态。

## 阅读队列

「学习材料」提供待阅读、稍后阅读、已归档和全部材料四个列表。新导入的材料和旧版本中的材料默认进入待阅读。待阅读先按高、普通、低优先级排列，同档再按安排日期和导入时间排序；没有安排时使用导入日期。稍后阅读与归档维持日期顺序，全部材料依次列出这三组。阅读和保存位置不会改变排序。

- **阅读优先级**：在阅读器中选择高、普通或低，默认普通。更改后保留日期和位置；筛选条件仍包含当前材料时继续显示，已不匹配时从列表中移除。高优先级不会让稍后阅读提前到期，也不会恢复归档材料。
- **稍后阅读**：点选「明天」「3 天后」「1 周后」，或填写下次阅读日期，默认为明天。快捷选项显示实际日期，选择或输入后，点击「保存阅读安排」才会生效；取消不会改变原安排。保存后移到稍后阅读列表，到指定日期自动回到待阅读。日期按当前设备的本机时区和日历计算。
- **归档材料**：从待阅读中收起，原文、阅读位置、摘录和关联卡片继续保留。归档后卡片仍按原来的 FSRS 安排复习。
- **加入待阅读**：从稍后阅读或归档中移回今天的待阅读列表，保留原先的阅读位置。

更改优先级或安排时，当前已显示的阅读位置与设置在同一事务中保存；保存失败会保留原状态和错误提示，可以重试。操作前快照与完整备份包含阅读安排和优先级。归档与删除的区别是：归档保留原文与出处，删除会解除关联。

快捷安排适用于原文和独立摘录，各自保存日期。在阅读轮次中，保存成功后继续下一篇；失败时保留选中的日期和当前篇，重试不会提前跳过材料。它是手动选择阅读日期，不会根据阅读次数自动延长间隔。

队列按日期运行，不自动判断材料是否掌握；需要结合理解反馈安排间隔时，使用下文的「自适应阅读间隔」。PDF 与 EPUB 由可安装的官方阅读器提供；网页抓取不在当前范围内。设计参考见 [Foliole 阅读笔记](READING_REFERENCES.md)。

## 批量整理与撤销

勾选材料，或点击「选择本页」「选择全部筛选结果」，再打开「批量安排」。确认页显示篇数和部分标题，可以统一设置优先级、稍后阅读日期、归档或加入待阅读。选择可以跨页保留；改变搜索、类型、优先级或队列会清除选择。「全部筛选结果」包括当前队列中的所有分页，不只屏幕上显示的材料。

整批安排在一次事务中保存，成功后才更新列表；失败保留选择和表单，可以重试。批量操作不代表读过材料，不推进递增间隔。更改日期或加入待阅读会恢复选中材料的活动状态，包括原先已归档的材料；设置优先级则保留原日期和归档状态。

「撤销阅读安排」恢复最近一次单篇或整批安排中的日期、归档状态、优先级和间隔。之后修改的标题、链接、阅读位置与卡片评分继续保留。阅读轮次因该操作进入下一篇时，立即撤销会回到原篇；若已继续前进，则只恢复安排。

只保留本次打开期间最近一次有效安排的撤销，刷新、退出、切库或恢复备份后清除。目标被删除、替换正文或再次改变安排时，旧撤销不能覆盖当前数据；账户库另有修订冲突保护。需要跨重启恢复更早状态时，使用操作前快照；快照会恢复整个学习库。

## 递增阅读间隔

读过一段后，点击「读过，安排下次」。弹窗会显示本次间隔和实际日期，点击「保存阅读安排」后生效。间隔依次为 **1 → 3 → 7 → 14 → 30 天**，之后保持 30 天，按本机日历计算。阅读轮次中保存成功会继续下一篇；保存失败保留当前篇，可以重试。

每篇原文和独立摘录分别记录上次间隔；新摘录从 1 天开始。打开材料、滚动、普通「下一篇」和取消弹窗都不会推进阶梯。使用「稍后阅读」自选日期、调整优先级、归档或加入待阅读时，上次间隔继续保留。归档期间收起「读过，安排下次」，恢复后可以接着安排。

「重置间隔」让下一次从 1 天开始，已安排的阅读日期保持不变，确认前可以取消。间隔随学习库、快照和完整备份保留，刷新或退出重开后继续。它用于安排再次阅读，与卡片的 FSRS 评分分别处理。

## 筛选材料

标题搜索、材料类型（全部 / 原文 / 摘录）与优先级可以组合使用，四个队列的数量会随筛选更新。未设置类型的旧材料按原文处理，未设置优先级时按普通处理；原文已删除的独立摘录仍属于摘录。这一列表筛选只匹配标题，不读取所有正文；查找正文使用独立的全文检索。

「阅读筛选结果」从当前列表的全部分页中选取待阅读材料。例如选择「摘录＋高优先级」，可以集中读完这一批。全部材料中的未来安排与归档内容不会加入本轮；稍后阅读、已归档列表及没有匹配项时，该按钮不可用。旁边显示当前列表总数和可阅读数量。

「清除筛选」恢复全部类型、全部优先级与空搜索词，保留当前队列。修改筛选条件会回到第一页。筛选只保留在本次材料页面中，刷新、离开页面或切库后恢复默认。

从原文列表点击「打开摘录」时会清除筛选并切到全部材料，保证目标可见；新导入材料或保存独立摘录后也会清除筛选。轮次中的摘录弹窗保持原来的阅读范围。

## 每日阅读与卡片复习

「学习概览」的「今日阅读」显示当前可读的原文与摘录数量。「开始今日阅读」按当前优先级和日期启动一轮；「管理学习材料」打开材料列表。稍后阅读和归档材料不计入今日数量。

一轮结束后，点击「去复习卡片」进入正常卡片复习，继续遵守卡组每日额度、暂停、暂缓与 FSRS 到期安排。阅读不会替你给卡片评分，也不把阅读数量计作复习次数。

## 连续阅读一轮

「开始一轮阅读」读取全部待阅读材料，不受列表筛选影响；「阅读筛选结果」只读取符合条件的待阅读材料。两种入口都先保存当前位置，再按优先级和日期固定本轮顺序。轮次中收起列表和筛选，筛选阅读会显示使用的范围；需要自行选材料时，点击「结束本轮」返回。

筛选轮次结束后，「再读一轮」继续使用相同条件，从当时的待阅读中重新选择；本轮中改为其他优先级的材料可能不再符合下一轮条件。返回材料列表后仍保留开始时的筛选，可调整或清除。

- **下一篇**：先保存当前阅读位置，再进入下一篇。最后一篇显示「完成本轮」，保存后到达结束页面。
- **稍后阅读 / 归档材料**：保留位置，保存安排后进入本轮下一篇。
- **结束本轮**：保存当前位置，回到材料列表；保存失败时停留在原篇，可重试。正文未能读取时也可直接结束，原位置保留。

每篇材料本轮最多出现一次。顺序在开始时固定，优先级调整留到下一轮生效；新导入、保存为摘录或后来到期的材料也留到下一轮。已删除、换了快照或不再待阅读的材料会跳过。

离开材料页、刷新或退出应用后，本轮结束，每篇材料已保存的位置继续保留。再次开始时按当前队列重新排列；轮次本身不进入备份。阅读到末尾不代表已经掌握，也不会产生 FSRS 评分。

## 保存独立摘录

在阅读预览或原文视图中选中文字，点击「保存为摘录」，填写标题后保存。无需先创建卡组或卡片。摘录正文保持对应原文片段，加入待阅读列表，并带有「摘录」标记；可以单独设置阅读优先级、稍后阅读或归档，位置也单独保存。新摘录默认普通优先级，不继承原材料的安排。

点击「查看出处」回到原文并高亮实际选区。同一段文字出现多次时，也能定位到选中的那一次。摘录保存独立正文；原文被删除后仍可阅读和制卡，页面会提示出处已解除。

原文与摘录都可以继续「保存为摘录」，最多嵌套 32 层，每次最多 10000 个 UTF-16 代码单元。每一级分别保存正文、阅读位置、日期、优先级和间隔；新摘录不继承父材料的安排。阅读器上方的出处路径可查看各级材料；复习回看时可逐级点击「查看出处」或点击路径标题，选区会定位到每一级的实际位置。

## 在原文中查找摘录

打开原文或摘录后，「本篇摘录」按选区在原文中的位置排列，显示标题、正文预览和关联卡片数；稍后阅读及已归档的摘录也会列出。每页五条。关联卡片数包含双向、多个挖空生成的卡片及暂停卡，不代表当前到期数量。

- **定位原文**：切回原始文本，选中实际范围并滚动到选区开头，也支持键盘操作。当前位置照常自动保存。
- **打开摘录**：先保存原文位置，再进入该摘录的独立阅读器。会切到全部材料以显示目标，保留摘录原有的日期和归档状态。保存失败时留在原页，可重试。
- **查看已有摘录**：再次选中相同范围时会出现提示，点击跳到对应列表页。相同文字出现在其他位置时不会混为同一段；仍可主动保存另一份。

阅读轮次中打开摘录会使用弹窗，关闭后继续原篇，顺序不变。列表与匹配不额外读取全部摘录正文；只有打开时才读取对应正文。删除摘录或恢复备份后，列表和卡片数随当前库更新。

## 从摘录创建卡片

1. 打开一篇材料，在阅读预览或原文视图中选中文字，点击「用摘录制卡」；已保存的摘录可直接点击「用此摘录制卡」。
2. 摘录会填入答案，在编辑器中填写问题；可以修改答案，也可以改为双向或挖空笔记。
3. 保存卡片。它使用所选卡组的正常复习规则，材料不会直接产生 FSRS 评分。

Markdown 预览中的选区会映射到保存的原文；无法精确映射时，可切回原文选择。相同文字出现多次时，记录本次实际选取的位置。列表中的「关联笔记」可以打开已保存的卡片。选区操作中的「制作挖空卡」会带入所选片段，保存前可在卡片编辑器中核对和修改。

复习显示答案后，点击「查看原文」打开快照。摘录处会高亮，页面定位到该位置。由独立摘录制作的卡片先显示摘录，点击「查看出处」可以逐级查看父摘录和原文；局部选区会定位到各级的对应位置。查看材料不会额外评分；关闭原文后继续按实际表现评分。

桌面本地库另有「通过 MCP 制卡」：选中摘录后主动分享给客户端，接收问答、双向或挖空卡草稿，在编辑器中核对并确认保存。草稿保存在本机，未完成的编辑可「保存草稿」后下次继续；分享授权不会恢复。草稿不进入备份，确认后的出处和普通摘录卡相同。[配置、限制与重试](MCP.md#从摘录生成草稿)

## 快照与外部文件

每次导入都会创建独立快照，标题或链接相同也不会覆盖旧材料。外部文件或网页发生变化时，旧卡片继续引用原先的快照。桌面工作目录会检测文件变化，列入待处理列表，由你比较并确认接受；不会自动合并正文，也不会自动抓取原网页。

通过导入窗口添加的文本以 UTF-8 保存，去除开头的 BOM，换行统一为 LF，保证各平台的选取位置一致。Markdown 沿用卡片的显示方式：支持经过清理的 HTML 和局部样式，不执行脚本，不下载外部资源。原文与摘录位置不因渲染而改变。普通文件导入不会扫描相邻附件目录；桌面工作目录中接受的相对路径图片、音频则另存不可变附件快照。[内容格式与 HTML 范围](USAGE.md#快捷制卡与内容格式)。

内置文本导入支持 `.txt`、`.md`、`.markdown`，每份材料最大 **1 MiB**、**250000 个 UTF-16 代码单元**；每条摘录最多 **10000 个代码单元**。普通中文、英文字符各计一个，部分 emoji 占两个。原材料与独立摘录合计最多 **10000 份**。PDF / EPUB / HTML / 图片使用上文的官方插件及各自限制；不提供网页抓取或图片 OCR，普通文本导入也不会扫描相邻目录。

## 导出、删除与恢复

「导出原文」下载保存的 UTF-8 文本 / Markdown 快照，不包含关联卡片及复习进度。需要迁移整个学习库时，使用「数据与备份」中的 `.repeaty` 完整备份，它包含材料、原文快照、阅读位置、阅读安排、递增间隔、优先级、摘录位置、卡片、媒体和进度；JSON 备份也支持，但仍受 100 MB 上限限制。

删除原材料时，会解除直接引用它的笔记和摘录的出处关联，已有独立摘录与卡片仍保留。删除独立摘录会解除关联笔记的来源，笔记内容、卡片与复习进度保留。删除卡片不会自动删除材料。

操作前会保存快照，可在「数据与备份」中恢复原文、摘录和出处。删除中间摘录时，只解除直接子摘录的出处；更深层的关联与各自正文保留，已生成卡片与进度继续可用。恢复完整备份或快照会替换整个当前学习库。

原文缺失、损坏或无法读取时会显示错误，不会从外部链接重新下载一份代替。可尝试重读或从完整备份恢复。

## 自适应阅读间隔

在「读过，安排下次」中将「间隔方式」改为「自适应」，选择本次理解情况：

| 反馈     | 用途                             |
| -------- | -------------------------------- |
| 需要再读 | 缩短间隔，尽早回来阅读           |
| 基本理解 | 按距上次阅读的天数与当前系数安排 |
| 已经熟悉 | 适当延长下次阅读间隔             |

页面先显示间隔和实际日期，点击「保存阅读安排」才生效。未设置过间隔的材料首次三档分别为 1、2、3 天，后续结合上次间隔与实际经过天数调整，限制在 1–365 天。每篇原文与摘录独立记录；这是一种阅读安排规则，不估算记忆保持率，卡片仍使用 FSRS。

已保存的自适应方式会在下次打开时选中。固定递增方式仍可使用，确认时切换；重置会清除两种间隔状态，保留已安排日期。手动日期、优先级、归档与恢复不会清空理解反馈。撤销阅读安排会恢复上一次反馈与间隔，后续卡片评分保留。

## 阅读与卡片混合学习

在「学习概览」的今日阅读区域点击「开始混合学习」，选择每篇材料之间复习几张卡片，默认为 3，可选 1–10。

卡片沿用正常 FSRS 队列、每日额度、暂停与暂缓规则；材料按开始时的待阅读顺序进入，每篇本轮至多处理一次。阅读时到期的卡片会在下一次切换时出现。只有一类内容可用时继续该类；新导入的材料留到下一轮。

阅读器保留摘录、制卡与出处操作。点击「完成阅读，继续学习」会先保存位置，也可以确认下次阅读日期、延后或归档后继续。直接完成阅读不自动填写理解反馈。保存失败会保留当前篇与表单，可重试；只在保存成功后推进。

混合界面分别提供评分与阅读安排的撤销。撤销评分保留已保存的阅读安排；撤销最近阅读安排保留卡片评分，适用时回到刚处理的材料。撤销或退出前会保存当前阅读位置，失败时留在当前项。

本轮顺序、进度计数和混合比例不跨重启保存。退出、刷新、恢复或切库后重新开始；已保存的卡片评分、阅读日期、反馈和位置保留。切换页面不会撤销已经提交的写入，迟到响应不会重新打开旧轮次。

数据规则见 [ADR 014](adr/014-adaptive-mixed-study.md)。v1.0 前的剩余工作见[发布清单](RELEASE_1_0.md)。
