# 桌面客户端

Repeaty 使用 Tauri 2、Vue 与 Rust。客户端直接打开学习目录，不需要账户或后台服务；安装包自带界面，学习数据存储在选择的文件夹中。

本分支正在接管桌面存储，尚未发布新安装包。已发布的 0.27.0 安装包仍是此前实现；不要将发布页旧包当成本分支的验证产物。

## 开发与构建

安装 Node.js、Rust 和 [Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)，然后运行：

```bash
npm ci
npm run desktop:dev
```

构建当前平台安装包：

```bash
npm run desktop:build
```

`npm run desktop:build -- --debug --no-bundle` 可生成包含网页资源的调试程序，无需开发服务器。只用 `cargo build` 得到的开发程序依赖 Vite 开发地址。

## 窗口标题栏

Windows、macOS 和 Linux 使用同一套应用绘制的标题栏与窗口按钮，跟随 Repeaty 的界面样式。拖动标题栏空白处移动窗口，双击切换最大化和还原；最小化、最大化与关闭通过 Tauri 调用系统窗口操作。窗口边缘缩放、最小尺寸、阴影及最大化后的工作区仍由原生窗口管理，具体外观可能随系统而异。关闭按钮先发起关闭请求，等待原有草稿和保存检查，再执行托盘或更新策略；确认允许退出后才完成原生窗口销毁。这个最终步骤不再重新发起关闭请求，避免开发页面刷新后残留的旧监听再次拦截。失败时保留关闭检查，并在标题栏提示重试。

Windows 11 的最大化 / 还原按钮接入系统 Snap Layouts 悬停菜单，布局选择由 Windows 处理，不绘制仿制菜单。窗口最小内容区为 500×400 逻辑像素；显示缩放和工作区会影响可用的布局分区。macOS / Linux 不启用 Windows Snap 接入；macOS 的原生交通灯菜单以及系统提供的移动、对齐交互也不能由自绘按钮完整替代。相关平台限制见 [Tauri 窗口定制](https://v2.tauri.app/learn/window-customization/)及 [Windows Snap Layouts 接入要求](https://learn.microsoft.com/windows/apps/desktop/modernize/apply-snap-layout-menu)。

标题栏的浏览器夹具测试只验证布局、按钮调用及状态更新。系统拖动、双击、边缘缩放、多屏缩放、macOS 窗口行为和 Linux 窗口管理器兼容性须分别通过原生客户端实机验证；未运行的平台用例不标记为通过。

Snap 接入及剩余窗口操作由用户按[窗口手动验收清单](DESKTOP_WINDOW_TESTS.md)测试，本轮不使用 computer-use。清单包含启动方式、Snap 设置、拖动与八方向缩放、最小化和两种关闭方式、弹窗、重启数据保留及多屏 / DPI 反馈格式；当前人工结果均待填写，自动检查不等同于实机验收通过。

## 工作目录

首次启动，在「工作目录」选择空文件夹创建学习库，入门卡组自动添加。选择「打开目录」可打开另一个学习库。应用会记住最近目录，重启后继续打开上次的学习库。

Windows 当前和最近目录使用普通路径显示，例如 `D:\tmp\repeaty-test`；网络目录显示为 `\\server\share`。界面隐藏系统的扩展路径前缀，文件访问和重新打开仍使用原始路径。

卡片正文和材料写为 Markdown，图片和音频单独存放；SQLite 保存调度、历史、阅读状态和持久草稿。偏好和插件开关也随目录保存。评分不会扫描 Markdown 或重写整库。

在 `notes/` 新建笔记文件后，进入「工作目录 → 重新扫描」，选择卡组与题型并确认添加。问答使用单独一行 `<!-- repeaty:answer -->` 分隔题面与答案，挖空可直接写 `{{c1::内容}}`。已有文件的正文编辑、改名保留身份与进度。方向或挖空编号被移除时保留退役记录，重新添加时恢复原卡片与调度。

外部删除文件后，可确认移除，并在「已移除的笔记」中搜索、分页和恢复。恢复路径已有文件时，可以改用其他 `notes/` 路径；不会覆盖占用路径的文件。应用内编辑和删除也保留可恢复记录。材料正文、格式和附件变化经确认后保存为新版本；已有摘录继续读取原版。「历史版本」可查看旧正文和位置。Markdown 支持 `assets/` 中的相对路径图片和音频，同名替换后可确认接受。外部修改会自动列入待处理列表；侧栏显示数量，返回窗口时会补检。见[目录结构与边界](WORKSPACE_MODE.md)。

本分支的工作目录格式已更新为 3，不自动迁移未发布的格式 1 / 2。请新建目录测试；旧目录保留。

备份或复制前先关闭学习库，再复制整个文件夹，包括 `.repeaty` 和 `assets`。没有旧库迁移或桌面上游切换功能；程序不会清理旧库。已有 `.repeaty` 内容导入仍可使用，但它不是包含所有辅助数据的目录备份。

## 阅读、插件与 AI

「学习材料」保存原文快照、摘录、阅读位置、阅读安排和理解反馈。材料可独立阅读，也可从学习概览进入混合队列。位置与评分在重启后保留；本轮队列不跨重启恢复。见[阅读用法](SOURCES.md)。

侧栏齿轮「设置」的「通用」分类提供界面语言和通知选项；「插件」分类可安装、更新、关闭、移除或重新加载外置插件，详情页不显示业务配置；插件配置按主题进入同一设置树，也可从详情中的「配置插件」直接定位；介绍和使用教程读取包内 README，在插件详情展示。官方答题历史和 LeetCode 也以独立包提供，不需要重编译客户端。代码保存在 `.repeaty/plugins/<id>/`，设置和业务数据随当前工作目录保存；复制来的未知代码须主动确认启用。关闭或移除代码保留题目、草稿、完整提交和进度。

LeetCode 协议在外置插件中实现，宿主只提供通用网络与凭据能力。登录凭据和代码信任记录保存在设备的私有存储，不进入工作目录；复制学习库到新设备后需重新确认代码并配置登录信息。见[插件开发](PLUGINS.md)和[LeetCode 配置](LEETCODE.md)。

在「设置 → 连接 → MCP 连接」连接 Codex、Claude Code 或 Claude Desktop。MCP 默认关闭；分享摘录和接收草稿需要主动开启。待确认草稿、附件和编辑内容保存在当前目录，重启后可以继续确认；MCP 密钥及分享授权不会随目录复制。见[MCP](MCP.md)。
