# 外观、阅读与导航

在 **设置 → 通用 → 界面** 调整界面语言、跟随系统的明暗模式、阅读排版、配色及辅助功能。设置随当前学习库保存，不改变材料正文、卡片内容或学习进度。切换学习库会恢复该库自己的设置；只读网页试用只保存到浏览器副本。

## 阅读排版

界面、阅读正文和代码可以分别使用不同字体。填写设备上已安装的字体名称，留空使用默认字体；没有安装的字体会回退，不下载网络字体。

正文可调整字号、行宽、行高及段落间距。界面整体、侧栏导航文字和列表文字可分别缩放。预览即时更新，狭窄窗口会限制正文实际宽度。官方 EPUB / HTML 阅读插件使用相同排版变量；PDF 保留原件布局，提供原始颜色、暖色纸张和反色显示。

**恢复默认外观** 会恢复本页全部外观偏好及保存的配色，不改变学习内容。字体名称、配色和数值必须符合允许范围，保存失败会显示提示并保留当前会话的效果。

## 明暗配色

分别编辑浅色和深色的文字、强调色、页面、内容及侧栏背景，以及选区、高亮和挖空颜色。切换“编辑配色”只选择要编辑的配色；实际明暗模式仍由“颜色模式”控制。

强调按钮自动选择较清楚的前景色。文字与背景对比度过低会显示提示。配色会传递到宿主提供的插件控件、页面、滚动条和阅读区域；插件自定义的固定颜色不会被强制覆盖。

可以命名保存最多 12 组配色，也可以展开 **导入或导出配色**，复制 JSON 到另一学习库。导入只接受已知颜色字段，不包含可执行样式或脚本。格式不正确不会应用配色；**恢复此配色** 仅重置正在编辑的明暗配色。

## 侧栏与工作区

在 **设置 → 通用 → 侧栏与布局** 选择入口显示状态、图标和上下顺序。默认窄侧栏仅显示图标，也可始终显示文字。入口保留可访问名称和提示，紧凑模式仍保留可操作的点击区域。

设置、帮助和当前正在使用的页面始终可见，避免隐藏后无法恢复。停用或卸载插件会移除其实际入口；重新启用时仍保留用户的排序和图标偏好。**恢复默认侧栏** 恢复默认顺序、图标、密度及显示状态，不卸载插件。

主侧栏宽度与展开状态沿用拖动和键盘调整。在学习材料中，材料列表与右侧上下文面板的宽度、列表 / 树形方式、上下文面板的显示状态也按学习库保存；窄窗口使用响应式布局。

## 学习状态与辅助功能

“学习状态图标”分别配置材料与卡片。材料树区分未安排、已安排和归档；卡片列表区分新卡、已安排和暂停。原有状态文字及评分语义保持不变。可以调整图形、颜色、尺寸、描边、双线及淡化；自定义路径只接受 24×24 视框内的 SVG `path d` 数据，不执行 SVG 标签、脚本或外部资源。

辅助选项包括图片变暗、字体平滑、增强文字与分隔线对比度和减少动态效果。系统的减少动态效果和强制对比色始终优先。键盘仍可操作设置、侧栏和分栏调整器；本页设置不会接管输入法或文本输入的原生编辑快捷键。

## 插件开发者

宿主的 SDK 控件已自动使用同一外观。自定义阅读器可引用这些 CSS 变量：

| 变量                                      | 用途                                     |
| ----------------------------------------- | ---------------------------------------- |
| `--font-ui` / `--font-mono`               | 界面 / 等宽字体                          |
| `--reading-font` / `--font-size-reading`  | 阅读字体与字号                           |
| `--reading-width`                         | 阅读正文的最大宽度；应同时限制为容器宽度 |
| `--line-height-reading`                   | 正文行高                                 |
| `--reading-paragraph-spacing`             | 段落间距                                 |
| `--reading-highlight` / `--reading-cloze` | 高亮与挖空颜色                           |
| `--ui-text` / `--ui-bg` / `--ui-primary`  | 文字、表面及强调色                       |

使用变量不需要让插件源码参与 Repeaty 编译。插件仍独立构建、按学习目录安装，并在运行时加载。
