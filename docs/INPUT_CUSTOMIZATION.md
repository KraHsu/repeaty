# 快捷键与鼠标手势

在「设置 → 通用 → 操作」中按命令搜索、录制或填写快捷键。使用 `Mod` 表示 Windows / Linux 的 Ctrl 和 macOS 的 Command；也可以明确使用 `Control` 或 `Meta`。最多保存三个替代按键，以逗号分隔。每项都可以取消绑定或恢复默认，全部快捷键可以统一重置。

同一使用场景中重叠的按键会显示冲突，保存时需先解决冲突。若外部设置包含冲突，软件不会任意选择一个动作执行。插件命令出现在相同列表，只有当前视图和启用实例允许执行时才会响应；停用插件会移除可执行入口，保留已保存的配置，便于重新启用后恢复。

输入法组合输入、按键长按、输入框与菜单导航不会触发应用全局快捷键。文本编辑仍使用系统原生撤销、复制、粘贴及选区操作；保存表单和添加挖空可以单独改键，但不能占用这些原生按键。弹窗关闭及无障碍控件的导航键保留自己的语义。

鼠标手势默认关闭。启用后在非编辑内容区域按住右键划动、松开执行，普通右键点击仍打开菜单。触摸、笔、左键选择和输入框不参与识别。默认左划后退、右划前进、左后向上到页首、左后向下到页尾；可更改、删除或录制最多八段的新手势。设置中的绘图区也接受左键，或直接使用 `L/R/U/D` 输入方向。

可以调整识别距离、轨迹采样间隔、颜色、线宽、透明度、轨迹及动作提示。Escape、窗口失去焦点、取消指针操作、切换学习库、停用手势都会取消当前划动。前进和后退只恢复普通页面及其筛选状态，不恢复正在进行的复习；离开阅读仍经过原有保存检查，切库后清空导航历史。

阅读工具栏、选区工具栏、右键菜单与复习菜单的顺序和可见操作在「菜单与工具栏」中调整。必要的编辑或退出入口保留。菜单中的快捷键提示与实际绑定同步；隐藏菜单项不会删除对应数据。

这些配置通过当前设置适配器保存，网页只读工作目录试用仍保存到浏览器副本。保存失败会提示重试，不将未保存的改动报告为成功。插件卸载不删除学习记录。
