# 使用指南

[返回首页](../README.md) · [在线使用](https://krahsu.github.io/repeaty/) · [开发文档](DEVELOPMENT.md)

GitHub Pages 提供纯前端版，学习数据存于当前浏览器。带后端版使用 Rust + SQLite，数据存于部署服务，需要持续连接服务；桌面版默认使用本机学习库，也可设置上游地址。三个版本通过 `.repeaty` 备份迁移。

首次打开会加入「从这里开始：FSRS 与 Repeaty」入门卡组，包含 **24 条笔记、27 张卡片**。点击「开始复习」，先回答再翻面。卡组介绍 FSRS 的 R / S / D、四档评分、目标记忆保留率，以及 Repeaty 的制卡和数据管理。

入门卡组覆盖正反面、双向、挖空、Markdown 表格与代码块、数学公式、图片和音频。所有卡片都从未学习状态开始，保留真实的评分记录；默认每天最多学习 30 张新卡，同笔记的其他卡片会按设置暂缓到明天。

已有学习库不会自动添加内容。需要时，可在「数据与备份」中点击「添加入门卡组」，按当前语言追加一份，不替换原数据。入门卡组可以编辑或删除，删除后不会因刷新而重新出现。切换界面语言也不会改写已有卡片。

卡片中的 FSRS 解释参考 [FSRS 项目的介绍](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)和 [Anki 的评分说明](https://docs.ankiweb.net/manual/studying#answer-buttons)。遗忘曲线为原理示意图，不是实际 FSRS 预测；图片与双音音频由本项目制作，随代码以 MIT 协议提供。

## 界面语言

顶部语言选择器支持 **English / 中文（简体）**。首次打开按浏览器语言偏好选择，识别英语和中文的地区变体；没有匹配语言时使用 English。手动选择保存在当前网站的 `localStorage`（`repeaty.locale`），刷新后沿用；存储不可用时仍可在本次会话切换。

导航、编辑表单、复习评分、搜索提示、通知、校验错误、日期、间隔和快照原因随界面语言变化，无需刷新。切换不改动卡片内容、卡组名称、标签、常用筛选、复习进度或已有快照，也不会结束当前复习。语言偏好独立于学习数据，不包含在学习数据备份中。入门示例在添加时使用当前语言；CSV 示例与 PWA 安装信息也提供两种语言，并随应用离线缓存。

正文与输入框采用 16px 基准字号，辅助信息至少 14px；浏览器默认字号与页面缩放会同步影响这些文字。窄屏按钮可换行、评分按钮两列排列。长题面使用 18px 左对齐正文，保留换行和完整内容，编辑器与复习页均支持长文本和多媒体。

## 笔记与卡片

一条笔记保存内容、标签、媒体和所属卡组，并生成一张或多张卡片。各张卡片分别保存 FSRS 进度、暂停和暂缓状态。

| 笔记类型        | 生成规则                                           |
| --------------- | -------------------------------------------------- |
| 正反面 `basic`  | 一张正面 → 背面卡片                                |
| 双向 `reversed` | 正面 → 背面、背面 → 正面两张卡片，媒体也随两面交换 |
| 挖空 `cloze`    | 每个不同挖空编号生成一张卡片，相同编号一起隐藏     |

挖空示例：

```text
法国的首都是 {{c1::巴黎::城市}}，日本的首都是 {{c2::东京}}。
```

支持 `{{c1::答案}}` 与 `{{c1::答案::提示}}`，编号 1–99；当前不支持嵌套挖空。挖空笔记的背面可留空，或填写额外解释。旧笔记保持纯文本显示；新笔记可选择 Markdown / 数学公式，编辑与复习共用同一渲染器，支持经过清理的 HTML 和样式。

编辑笔记时，仍然存在的卡片保留原 ID、复习进度及暂停状态；新增方向 / 挖空编号生成新卡片。移除某个方向或挖空编号会删除对应卡片和记录，编辑器会要求确认，并在保存前创建快照。删除笔记会删除其所有关联卡片。

Markdown 代码块可在开头写语言名，例如三个反引号后接 `python`、`rust`、`js` 或 `sql`。常用语言会高亮；未注明或未识别的语言按代码原样显示。中文与闭合加粗标记紧邻时，例如 `**中文：**中文`，渲染时会按 `**中文：** 中文` 处理；保存的文字不变。

## 复习操作与答题历史

复习时按 `E`，或打开「更多操作 → 编辑」，可以修改当前卡片。保存后回到问题面，重新作答；取消保留原来的翻面状态。编辑本身不产生评分。移除方向 / 挖空编号仍适用上面的确认规则。

「更多操作 → 添加」或 `A` 打开新笔记，沿用当前卡片的卡组和内容格式，保存或取消后继续原卡片。「删除」或 `Ctrl / ⌘ + Delete` 会先确认，再删除整条笔记及其全部关联卡片与记录。暂缓和暂停也可按 `B`、`S` 操作。

按 `Ctrl / ⌘ + Z` 或顶部撤销按钮，依次撤销最近的学习库操作，包括评分、添加、编辑、删除、导入、暂停、暂缓和阅读安排。当前会话最多保留 20 步；撤销删除会恢复原 ID、关联记录和附件。关闭应用或切换学习库后清空这段历史；评分仍可使用持久保存的评分前状态撤销。恢复备份或快照、首次发出一次判题提交、确认保存 AI 草稿后，会清空通用操作历史。已经提交到 LeetCode 的代码不能撤回。

阅读位置自动保存、界面偏好和导出不占撤销步骤。输入框内的 `Ctrl / ⌘ + Z` 由系统撤销文字输入，输入法组字期间不触发应用快捷键。目前没有重做。

答题历史插件在卡片上方显示过去的评分，末尾虚线圆表示本次作答。在「设置 → 插件 → 答题历史」可关闭插件、调整最近 1–50 次的显示长度，或选择翻面前显示。颜色图例和每次评分的日期可在设置及圆球提示中查看。历史仅针对当前卡片，撤销评分后同步移除对应圆球。

卡组卡片和卡组内容页分别显示今日可学的新卡、学习中卡片和到期复习卡片，也显示未学总量、稍后到期及额度限制。今日可学数量已应用暂停、暂缓、插件和每日额度。

## 设置与 AI 制卡

右上角「设置」集中管理界面语言、通知和插件。信息通知默认在顶部弹出，5 秒后关闭；鼠标悬停或键盘聚焦时暂停计时。警告与错误需手动关闭。可分别关闭三个级别的弹出显示，此时消息在页面内显示。

「设置 → AI 制卡」提供可以直接粘贴到 GPT 网页或其他 AI 聊天中的制卡说明，也可下载 `SKILL.md` 安装到支持技能的工具。将说明与本次材料一起发送给 AI，让它生成 CSV；在卡组中选择「批量导入 → CSV / TSV」，先检查预览再导入。不需要 MCP、账户凭据或完整学习库备份。[Skill 文件](../public/skills/repeaty-cards/SKILL.md) · [CSV 示例](../public/skills/repeaty-cards/example.csv)

旧版数据、JSON 备份和快照自动迁移为当前学习格式 v13：原卡片 ID、内容、调度状态和复习记录保留，v1 旧卡转换为基础笔记，已有笔记保留原题型；v5 库补空材料列表，v6 库保留已有材料，不补写阅读位置；v7 库保留阅读位置，已有材料默认可阅读，不补写安排；v8 库保留安排，旧材料按普通优先级处理，不补写优先级；v9 库保留已有阅读设置，不补写摘录类型或出处；v10 库保留全部原记录，不补写递增阅读间隔；v11 库保留原关系，不生成额外摘录；v12 库保留阅读安排，不补写理解反馈或确认次数。已有快照继续保留，初次迁移旧版整体 JSON 库时在同一事务中创建升级前快照。v1 记录没有评分前状态，无法撤销；无法判断属于复习还是学习步骤的旧记录保留为 legacy，不计入新版每日复习额度。当前 IndexedDB 为 v16：v8 加入材料元数据表，v9 增加桌面本地制卡草稿的独立存储，v10 支持材料阅读位置，v11 支持日期安排与归档，v12 支持阅读优先级，v13 增加独立阅读摘录，v14 增加逐篇递增间隔，v15 允许多级出处并保留原有记录与草稿；原文快照按需读取，沿用附件存储和回收规则。旧页面不能继续以旧版本写入。升级被旧页面阻挡时，会提示关闭旧标签页。

## 插件与 LeetCode 题目

插件由部署者安装，主导航「插件」中可开启或关闭。关闭后题目与进度保留，但不进入复习和专项练习队列，也不占用每日额度。开关保存在当前浏览器，其他设备单独设置；未安装或版本不匹配的插件同样保留数据。

LeetCode 仅在桌面版内置，在插件设置中填写本机登录信息，无需浏览器扩展。添加卡片时点击「添加 LeetCode 题目」，或选择「插件题目 → LeetCode」，选择站点并填写题目链接或英文标识（如 `two-sum`），读取后保存。默认中国站，可切换国际站；后续新题沿用上次站点，每张已保存题目保留自己的站点。复习时可编辑代码、提交到 LeetCode 判题，并手动或自动评分。[配置、评分规则与限制](LEETCODE.md)

从「练习历史」或卡片旁的历史按钮查看历次代码、判题结果和评分，可按题目、卡组、结果筛选。提交中断后，可在题目中粘贴 LeetCode 提交编号或详情链接，核对后继续查询原提交。

## 从材料制作卡片

打开「学习材料」，导入文本 / Markdown 或粘贴正文。可按标题、原文 / 摘录与优先级组合筛选，点击「阅读筛选结果」逐篇阅读符合条件的待阅读材料。选取原文中的一段文字，点击「用摘录制卡」，填写问题后保存；摘录会先填入答案，仍可修改。

原文和独立摘录均可通过「编辑材料信息」修改标题、来源链接，正文、出处与学习进度保留。

阅读原文或 Markdown 预览时会自动保存位置，列表中的「继续阅读」可回到保存处。重新打开材料时沿用最近阅读的位置和显示方式；退出前可点击「保存阅读位置」并等待保存完成。阅读不产生 FSRS 评分。

「待阅读」列出当前可读材料，「稍后阅读」可安排到明天或指定日期，届时自动回到待阅读；「归档材料」保留原文、位置和关联卡片。归档或延后后可「加入待阅读」，恢复为今天可读。阅读优先级可选高、普通、低，默认普通；待阅读先按优先级、再按日期排列。高优先级不会提前释放稍后阅读或归档材料。阅读安排按本机日期计算，与 FSRS 复习分别管理。

点击「开始一轮阅读」按当前待阅读顺序连续阅读，「下一篇」保存位置后切换；延后或归档后继续本轮，最后可「完成本轮」。保存失败停留在原篇。每篇本轮最多出现一次，调整优先级留到下一轮生效；离开材料页或退出应用后结束轮次，已保存的位置继续保留。

复习显示答案后可点击「查看原文」，回到原文快照中的摘录位置。材料随完整备份保存；独立删除材料时，卡片内容和复习进度保留。[详细用法与限制](SOURCES.md)。

## 每日学习与复习控制

- 每个卡组可设置每日新卡与到期复习上限，默认分别为 **20 / 200 张**，0 表示不引入该类卡片。
- 额度按本机日历日重置。新卡按首次学习的卡片数扣减，正式复习按当天进入复习的不同卡片数扣减；学习 / 重学步骤继续完成，不受这两项额度限制。
- 优先顺序为到期学习 / 重学、到期复习、新卡。四档评分由 `ts-fsrs` 计算下次时间，按所属卡组的目标记忆保留率调度（默认 90%，可设 70%–97%），关闭随机间隔扰动。预览与实际评分使用同一设置；调整设置只影响之后的评分，不立刻重排已有卡片。
- 「撤销上次评分」恢复评分前调度状态、移除该次记录，并重新计算额度；连续撤销可逐步回退，重新打开页面后仍有效。不会回退笔记内容修改或暂停操作。
- 「暂停此卡」持续生效直到手动恢复；「今天暂缓」在本机日历进入下一天后自动解除。两者都不改变记忆进度。
- 卡片列表可批量暂停、恢复、暂缓或取消暂缓。统计展示实际复习次数，首页待学数量已经应用额度。
- 默认评分后自动暂缓同一笔记的其他可用卡片至明天，卡组设置中可关闭。撤销评分会撤回该评分造成的自动暂缓；手动暂停 / 暂缓不受影响，也可在列表中取消自动暂缓。
- 正式复习遗忘达到卡组阈值后自动标记「顽固卡」，默认 8 次，0 关闭。新卡初学失败不计入这个阈值。可用 `is:leech` 筛选，或批量清除标记；不会自动暂停。清除后再次正式遗忘、仍超过阈值时会重新标记。
- 复习页支持空格翻面、1–4 评分、Esc 结束。输入框保留原生文字编辑快捷键；按钮上的空格仍用于点击按钮。

## 快捷键

按 `?` 或顶部快捷键按钮可查看帮助。弹窗打开、输入法组字或正在保存时，不触发页面快捷键。

| 快捷键                 | 操作                           |
| ---------------------- | ------------------------------ |
| `Ctrl / ⌘ + Z`         | 撤销最近操作；输入框内撤销文字 |
| `A`                    | 添加卡片；复习中沿用当前卡组   |
| `E`                    | 编辑当前复习卡片               |
| `Ctrl / ⌘ + Delete`    | 确认后删除当前笔记             |
| `B` / `S`              | 复习中暂缓 / 暂停当前卡片      |
| `B`                    | 未在复习时打开卡片列表         |
| `R`                    | 未在复习时开始复习             |
| `/`                    | 打开卡片列表并聚焦搜索         |
| `Space` / `1–4`        | 翻面 / 评分                    |
| `Esc`                  | 关闭弹窗或菜单，退出复习       |
| `Ctrl / ⌘ + Enter`     | 保存当前表单；新笔记保存并继续 |
| `Ctrl / ⌘ + Shift + C` | 将正面选中文字挖空             |

在弹窗外按下并松开鼠标才会关闭弹窗。从输入框拖到弹窗外、从外面拖进来，或点击弹窗内的空白处，都保留当前内容。关闭按钮、取消和 `Esc` 仍可关闭。

## 快捷制卡与内容格式

桌面编辑器并排显示题目和答案，窄屏自动改为单栏。字段区域独立滚动，顶部关闭和底部保存按钮始终可见。点击各面的「添加图片 / 音频」选择附件，可在保存前预览或移除。

- 新笔记默认使用 Markdown，支持加粗、列表、引用、表格、代码块、链接以及 `$行内公式$` / `$$独立公式$$`，也支持 `\(行内公式\)` / `\[独立公式\]`。公式由本地打包的 KaTeX 渲染，字体包含在离线缓存中；不加载 CDN。需要显示原始标记时可切换为纯文本。
- 在正面选中文字，点击「挖空」或按 `Ctrl / ⌘ + Shift + C`，自动切换挖空类型并使用最小未占用编号。可挖空包含平衡 LaTeX 花括号的公式，不支持嵌套挖空。
- 可将剪贴板中的图片直接粘贴到问题 / 答案输入框，作为对应面的本地附件；继续沿用每面 8 个、每个 10 MB 限制。
- 「保存并继续」成功后清空本条内容与附件，保留卡组、题型、格式和标签。新增笔记时 `Ctrl / ⌘ + Enter` 保存并继续，编辑已有笔记时保存关闭。保存失败时保留输入。
- 展开生成预览可同时查看实际题面、答案、公式和附件。普通正文默认左对齐，图片、独立公式和表格居中；空行分隔的段落比段内换行有更大间距。纯文本同样区分段落和换行。
- Markdown 中的外部图片仅显示占位文字，请通过附件保存图片。HTML 也不加载外部图片、字体或 CSS 资源；脚本、事件处理、表单、嵌入页面、危险链接和可信 TeX 扩展禁用。

可以在 Markdown 中插入带 `style` 的 HTML；代码块中的 HTML 仍按代码显示。例如：

```html
<div style="padding: 1rem; border: 1px solid #66865c; border-radius: 12px">
  <strong style="color: #48683e">定义</strong>
  <p>这里放解释、例子或提示。</p>
</div>
```

也可在正文中写 `<style>.hint { color: #48683e; }</style>`，搭配 `<span class="hint">提示</span>`。样式只作用于这一面的内容；预览、题面、答案和材料不会互相修改样式。常用颜色、字号、间距、边框、网格等 CSS 可用；资源加载、CSS 转义、`@import`、`@font-face` 等规则会移除。HTML 的 `id`、事件和用于应用控制的属性也会移除。需要排版时请使用 `class`。

## 高级搜索与专项练习

卡片列表支持以下搜索条件，可以用空格组合（AND），用 `-` 排除，用双引号包围含空格的值或短语。标签与卡组名按完整名称匹配，忽略大小写。

| 示例                                 | 含义                                       |
| ------------------------------------ | ------------------------------------------ |
| `tag:英语 -is:suspended`             | 英语标签，排除暂停卡片                     |
| `deck:"Study notes" "active recall"` | 指定卡组中的关键词短语                     |
| `type:leetcode`                      | LeetCode 插件题目                          |
| `type:cloze is:new`                  | 新的挖空卡                                 |
| `is:leech lapses:>=3`                | 顽固卡且正式遗忘至少 3 次                  |
| `due:<=7`                            | 7 个本机日历日以内到期，包括已经逾期的卡片 |
| `due:<0`                             | 到期日期早于今天                           |

`is` 支持 `new / due / review / learning / suspended / buried / leech`。`due` 和 `lapses` 支持 `= / < / <= / > / >=`，省略运算符表示相等。`is:due` 按实际到期时刻判断，不扣除额度或排除暂停；搜索结果可结合状态筛选进一步缩小范围。无效条件会显示错误。

展开「高级搜索、常用筛选与专项练习」可保存、更新、删除常用筛选，最多 100 个。保存的是条件，下次打开时重新查询；随完整备份和快照保存。删除卡组时清理该卡组限定的筛选。

专项练习从筛选结果取前 1–500 张可用卡片，每张本轮练习一次，跳过暂停 / 今日暂缓，保留原卡组。提供两种模式：

- **只练习，不改进度**（默认）：评分和撤销仅作用于本轮，不写入复习记录，不改变 FSRS 状态、额度、自动暂缓或统计。结束 / 刷新后本轮结果不保留。
- **评分并更新进度**：允许提前复习和超过每日额度；按所属卡组的 FSRS 设置评分，写入正式记录并计入当天用量，触发自动暂缓及顽固卡标记。撤销恢复调度与关联变化。选择「重来」后，本轮不会立即重复，后续进入正常到期队列。

## 批量导入与编辑

在「全部卡片」或卡组页面点击「批量导入」，选择目标卡组和导入格式。

**Anki .apkg**：支持标准两字段问答、双向、挖空和包内图片 / 音频，确认前可预览并下载报告。新笔记作为新卡添加，不导入 Anki 的学习进度；相同 GUID 默认保留，可逐条比较并选择更新内容，仍存在的卡片保留原进度。类型或挖空编号导致卡片增删时需另行确认。新版压缩包和旧版兼容包均可读取。[支持范围与限制](ANKI.md)。

**CSV / TSV**：选择文件或粘贴文本。要求 UTF-8，最大 2 MB、5000 条笔记，支持带引号的分隔符、双引号转义和多行字段。

```csv
type,front,back,tags
basic,hello,你好,英语|问候
reversed,apple,苹果,英语|名词
cloze,法国的首都是 {{c1::巴黎::城市}}。,位于塞纳河畔。,地理
```

`front`、`back` 为必需表头；`type`、`tags`、`format` 可选。`format` 支持 `plain / markdown`，默认 `plain`；缺省类型为 `basic`，标签用 `|` 分隔。整个文件校验通过并预览后才允许导入。默认跳过同卡组中题型、格式、正面、背面均相同的笔记，包含文件内部重复项。示例文件位于 [中文示例](../public/example.csv)和[英文示例](../public/example.en.csv)。

勾选卡片后可批量移动所属笔记、添加 / 移除标签或删除笔记。笔记级修改作用于全部关联卡片；复习进度保留。卡片列表每页 50 张，可跨页勾选，改变搜索或筛选条件会清除选择。

## 图片、音频与备份

笔记两面均可添加媒体，每面最多 8 个，每个文件最大 10 MB。支持 PNG / JPEG / WebP / GIF 图片和 MP3 / WAV / OGG / M4A / WebM / FLAC / AAC 音频；具体音频解码取决于浏览器。纯前端版将媒体作为 Blob 独立保存在 IndexedDB，后端版保存为 SQLite BLOB，复习评分不重写媒体内容。只有点击保存后才会写入附件。

「数据与备份」提供：

- **`.repeaty` 完整备份包**（默认）：ZIP 容器内包含版本清单、约 1 MiB 一块的 NDJSON 学习记录和原始媒体文件；文本压缩，媒体不转 Base64。归档文件及解压后内容均限制为 2 GiB，单个媒体仍为 10 MiB。导入会检查版本、记录数量、引用、媒体长度、CRC 校验和及异常条目，确认后再用事务替换数据。
- **直接保存到文件**：支持文件选择器的浏览器可流式写入用户指定的文件，避免在内存中拼出整个归档。普通下载仍会生成最终 Blob，超大备份优先使用直接保存。两种方式均支持进度与取消。
- **JSON 备份**：保留导入和导出，继续沿用 100 MiB 限制。新导出使用 v13，支持阅读位置、安排、递增间隔、优先级与独立摘录；旧版客户端不能读取新格式，旧备份仍可在新版恢复。
- **自动快照**：应用启动 / 使用期间对变化的数据每 30 分钟保存；删除、编辑已有笔记、批量修改、导入与恢复前额外保存。相同版本不重复保存，最多保留最近 10 份。
- **快照恢复**：恢复笔记、调度与引用的媒体，操作前另存当前数据。旧快照到期后，不再被当前数据或任何保留快照引用的媒体才会清理。

当前 `.repeaty` 容器为 v10，学习数据与 JSON 备份为 v13；仍支持恢复旧 `.repeaty` v1–v9 和旧 JSON 备份。原文、独立摘录、出处、阅读位置、安排、递增间隔与优先级随完整备份与快照恢复，独立导出原文只包含正文。

备份导入按块解码，但确认前仍需在内存中校验完整的结构化记录和持有媒体 Blob；不承诺在所有设备上处理到格式上限。

媒体 ID 在导入外部备份时重新生成，以免覆盖已有快照引用的文件。纯前端版在 IndexedDB 事务中保存内容和附件。后端版先上传不可变附件，再在 SQLite 事务内检查修订号、创建快照、更新记录和附件引用；失败时学习数据整体回滚，未引用上传保留一天供重试，之后在后续清理时回收。过期标签页的写入会被拒绝，提示刷新。

纯前端版的数据和快照按浏览器及 origin 隔离。清除网站数据会同时删除卡片、媒体、快照与离线缓存；更换域名、协议、端口或浏览器不会自动迁移数据。自动快照无法替代导出到其他位置的完整备份。

后端版的数据不随清除浏览器缓存而删除，需由部署者备份 SQLite；浏览器登录会话使用 HttpOnly Cookie。界面偏好、插件开关及未完成的代码草稿仍保存在浏览器。后端连接失败时会提示错误，不会另建本地学习库。

## 离线使用

此功能适用于纯前端版。后端版不启用离线缓存，制卡和复习均需要服务可访问。

在线打开应用后，在「数据与备份」看到「离线已就绪」，即可断网重新打开、刷新、制卡和复习，保存过的图片与音频也可离线使用。支持的浏览器可将它安装为独立 PWA。首次打开与下载更新需要联网。

新版本准备好后，应用会提示刷新，由你选择更新时间。安装 PWA 不会创建云端账号，也不会将学习数据同步到其他设备。

自适应阅读与混合学习见[材料使用说明](SOURCES.md#自适应阅读间隔)。混合轮次在退出或刷新后重新开始，已保存的日期、位置和评分保留。
