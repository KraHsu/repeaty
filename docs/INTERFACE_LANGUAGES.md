# 界面语言与语言包

在「设置 → 通用 → 界面」选择语言，默认跟随系统。切换只影响界面与日期、数字、时间单位，不会翻译卡片、材料、标签或已创建的入门卡组。

语言选择包含简体中文、繁体中文、英语、德语、西班牙语、法语、意大利语、日语、韩语、波兰语、巴西葡萄牙语和俄语。中英保留完整的现有消息目录；新增语言提供核心导航、学习操作、设置分类和公共控件译文。尚未翻译的技术说明与错误回退英文，官方插件按自身提供的翻译回退。新增译文尚未经过母语审校，不能把语言选择可用视为所有内容已翻译。

「设置 → 通用 → 语言」可导出当前有效译文为 JSON，编辑后导入当前学习库。导入先检查语言、消息名称及 `{name}` 等占位符，再预览并确认应用。它不会执行脚本，也不能改变学习内容。移除自定义翻译恢复内置文本。

```json
{
  "version": 1,
  "locale": "ja",
  "messages": {
    "保存": "保存",
    "打开卡组 {p0}": "デッキ {p0} を開く"
  }
}
```

消息名称以导出文件为准；可只保留需要覆写的条目。未知消息、丢失占位符、空译文或超大文件会被拒绝。语言包与设置随学习库保存，保存失败保留当前译文与导入预览。

## 插件本地化

SDK 1.15 的 `locale` 提供上述 BCP-47 语言标记。组件直接读取它会在切换语言时更新；不要假定除 `en` 外的语言都是中文。`createTranslator` 为插件提供隔离的目录及指定回退，不能覆写宿主或其他插件的文案：

```ts
import { createTranslator } from '@repeaty/plugin-api'

const text = createTranslator({
  en: { saved: 'Saved {count} items' },
  'zh-CN': { saved: '已保存 {count} 项' },
  ja: { saved: '{count} 件を保存しました' },
})
// 在 computed 或渲染函数中读取，语言变化时会更新。
text('saved', { count: 2 })
```

共享控件的辅助功能文案使用宿主语言。正文、设备凭据和插件私有数据不应作为翻译目录输出。

需要等待设置实际保存的插件可使用 `await persistSetting(key, value)`；它与 `readSetting` / `writeSetting` 使用相同的插件命名空间，在停用或切库后拒绝迟到响应。
