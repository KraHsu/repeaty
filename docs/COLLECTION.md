# 收集材料与连接来源

学习材料页面包含“阅读材料”“收件箱”和“来源”。三者使用同一个学习库：收件箱保存待整理的材料；阅读材料参与已有阅读安排；来源负责检查外部变化并生成待确认候选。

## 收集与整理

“收集材料”支持多文件、目录、拖放、剪贴板，以及粘贴文字。文件先按格式匹配已启用的阅读器插件；文本和 Markdown 可直接读取。PDF、EPUB、HTML、图片等格式使用独立官方阅读器插件。同一格式有多种导入方式时，在预览前逐文件选择，例如 EPUB 可选择独立章节或顺序阅读。

预览列出新增、重复和无法处理的项目。选择目的地和材料后一次保存；取消、解析失败或保存失败不留下半批材料。保存失败时可以保留预览重试。相同来源和内容复用已有材料，不重置学习进度。不同来源文件中内容相同但身份不同的材料不会自动合并。

收件箱内容可直接阅读、从选区制卡，随后修改标题和来源链接并整理到阅读材料，或归档后再恢复。尚在收件箱中的材料不进入混合学习队列。所有状态均随学习库保存并支持既有备份及撤销。

输入路径会过滤隐藏目录、临时文件和不安全路径。每批原始文件总大小不超过 128 MiB、最多 2,000 个文件，转换后最多 1,000 份材料、正文与资源合计不超过 256 MiB；普通文本为 UTF-8、单份最多 1 MiB / 250,000 个 UTF-16 字符。文档阅读器还遵守各自的格式限制。明确列出的跳过项需要在确认前检查。

## 来源与更新

在“来源”中连接 Markdown / 文本目录，或者安装并启用官方 Obsidian、Readwise 插件后连接对应来源。插件只提供读取和转换逻辑，连接、检查周期、候选确认与存储事务由宿主管理。第三方插件使用同一套公开接口。

连接器检查成功后列出新增、更新与缺失候选。检查本身不覆盖材料，不修改正在复习的卡片。确认更新时保存此前正文为历史版本，已有摘录和卡片仍引用原来的版本；本地已编辑时并排展示本地与来源内容，必须明确采用。忽略某个版本后，同一版本不会反复提醒，后来发生的新变化仍可再次出现。

来源重命名可在新增候选中选择已关联的本地材料重新关联，保留材料身份、旧版本及学习历史。确认“缺失”只标记来源状态，不删除本地材料。断开来源或停用、卸载插件同样不会删除已保存材料、卡片、历史和附件。

可选择手动或定时检查。定时检查在应用运行、学习库已打开且连接器可用时执行；不会在关闭软件后启动独立后台服务。失败、限流与取消不会把部分响应当成完整快照，也不会据此推断文件被删除。

桌面目录授权保存在设备上并绑定学习库；移动学习库到另一台设备后需重新授权。浏览器通过选择目录取得本次会话的只读文件快照，刷新后需重新选择目录；网页试用不会写入原始目录。

## 原地检索外部目录

桌面版可将 Markdown / 文本目录连接为“只读索引”。正文保持在原位置，索引是设备上的可重建 SQLite 缓存，不成为学习库正文。更新索引会反映新增、删除、改名和内容变化；取消或失败保留上一次完整索引。

搜索后可只读预览原文，或明确点击收集，将选定内容复制到收件箱。读取前后会核对文件状态；外部文件变化时需要重新检查，不把过期结果当成当前原文。断开目录会撤销授权并清理该目录的派生索引。

## 跨应用快捷收集

桌面设置 → 连接 → 快捷收集可启用并修改全局快捷键。先打开学习库，再在其他应用中触发收集，内容保存到当前库的收件箱。快捷键占用、无选区、权限不足或保存失败均显示反馈；保存失败的内容可在设置中重试或放弃。

Windows 使用 UI Automation、macOS 使用辅助功能接口读取当前选区，具体应用必须支持对应接口。macOS 需要用户授予辅助功能权限。也可选择剪贴板模式，先复制再触发快捷键，支持文字、图片和文件；收集操作不改写剪贴板。Linux 使用剪贴板模式，系统快捷键是否可用取决于桌面后端；不支持时仍可在软件中手动收集剪贴板。

原生窗口、跨应用选区、系统权限与热键冲突需要对应平台实机验证。Rust 和浏览器夹具测试不能替代这些验收。

## Readwise 原件与凭据

Readwise Token 通过设备凭据 API 保存，不进入学习库、插件配置或备份。API 获取正文、高亮和可用的原件位置；远程内嵌图片不会自动下载。导出目录中的本地附件在采用候选时保存为版本资源，可离线使用。

PDF / EPUB 原件由用户点击后单独获取。远程下载显示原生域名确认，只发送不带凭据的 HTTPS GET，不跟随重定向，最大 64 MiB，并核对文件格式；临时签名链接只保留在当前运行内，过期后需重新检查来源。本地导出原件直接从已授权目录只读导出。原件可随后通过文档收集入口交给相应阅读器，不将 Readwise 文本投影的位置误用于 PDF / EPUB。
