# Repeaty · B 方向绿色原型

用户已选择 **B 的中央卡组布局**，继续沿用 Repeaty 的绿色系。本目录保留可操作的独立审查原型。经用户追加授权，B 的布局和绿色主题已接入仓库 `src/` 中的真实应用；生产仍复用 Nuxt UI 与公开插件 SDK，不依赖此原型的 PrimeVue、模拟数据或专用 JSON。生产落地与验证见 [共用界面与排版](../../DESIGN_SYSTEM.md#绿色-b-设计接入真实应用2026-10-28)。

## 设计约定

| 用途 | 颜色      |
| ---- | --------- |
| 主色 | `#34674d` |
| 背景 | `#f3f5f0` |
| 正文 | `#243c31` |
| 说明 | `#52665a` |

- 中央卡组是首页唯一主角，导航与次要操作退到周边；其他页面共用内容容器和标题锚点。
- 保留原标题栏的 Repeat2 / Repeaty 标识与原 favicon；学习入口和管理入口以分割线区分，帮助与其他侧栏选项共用展开文字、收起图标的规则。
- 展开 / 收起开关固定在侧栏左上方，切换过程中按钮坐标不随栏宽移动，方便在同一位置连续操作。
- 去除重复眉标、标题和无贡献说明。正文 16 px、说明 14 px、阅读正文约 20 px；控件以 44 px 高度、8 px 圆角为基础。
- 不使用装饰图片：卡组、问题与阅读材料就是学习界面的主要内容，图片不会帮助本轮任务。
- 动效分为按压、内容切换、反馈三类：按压 80 ms，首页入场 340 ms，卡组切换 220 ms，导航展开 240 ms，提示消息 180 ms。遵循 `prefers-reduced-motion`，降低动态效果时关闭动画与过渡。

## 可审查的交互

- **学习概览**：切换和创建卡组，查看对应卡片与复习入口。
- **卡片**：搜索、筛选、编辑、暂停，以及带确认的删除。
- **复习**：问答翻面、评分、复习中编辑和退出确认。
- **设置**：软件与插件共享分类、字段布局和控件；设置变更保存到浏览器。
- **插件**：列表、详情 README、启停状态；配置入口转到统一设置。
- **学习材料**：两篇可读材料，段落摘录经编辑确认后保存为卡片。
- **备份与恢复**：实际下载 JSON；选择文件后先校验，再确认替换。
- **统一控件**：文本、多行文本、单选、多选、滑块、开关、复选框、数字输入，以及验证、禁用、加载和按钮状态。此页的示例值只在页面内临时改变。

初始数据为 4 个卡组、12 张卡片，每组 3 张，其中 2 张待复习、1 张新卡；累计复习从 0 开始。复习只展示本轮问答、评分状态和计数，**没有接入 FSRS 调度**，不能据此判断真实学习进度或下次复习间隔。

## 数据与能力边界

所有保存仅使用浏览器 `localStorage` 键 **`repeaty-design-b-v1`**。本目录不读取、写入或迁移真实学习库。重新载入会保留此浏览器中的原型修改；删除该键后再刷新可恢复初始数据，不涉及其他存储键。

导出文件是此原型专用的 JSON，标识为 `kind: "repeaty-design-b-prototype"`、`version: 1`。它包含卡组、卡片、设置、插件启停和复习计数，**不是 Repeaty 正式学习库备份，也不是 `.repeaty` 格式**。恢复只接受此专用格式并校验字段，确认后替换原型数据；不会执行文件中的 HTML 或脚本。

语言选择仅保存所选值，尚不翻译页面。插件启停展示界面状态，没有安装或加载外部插件包。工作目录路径用于展示布局，目录打开和检查按钮禁用；标题栏窗口控件为装饰，不调用原生窗口 API。此原型不能作为目录检测、安装包、平台窗口或迁移验收结果。

## 技术与运行

独立 Vue 原型使用 **PrimeVue 4.5.5** 和 **`@primeuix/themes` 1.2.5**，已按这两个具体版本核对 MIT 许可并固定版本。组件选型与本原型的视觉需求相关；当前的 PrimeVue 5 不属于本次依赖升级范围，也不代表生产组件库已选定迁移方案。

从仓库根目录执行：

```powershell
npm ci --prefix docs/designs/b-prototype --workspaces=false
npm run dev --prefix docs/designs/b-prototype
npm run build --prefix docs/designs/b-prototype
npm exec --prefix docs/designs/b-prototype -- playwright install chromium
npm run verify --prefix docs/designs/b-prototype
```

开发入口为 `http://127.0.0.1:4194`。构建输出到本目录的 `site/`，该目录已忽略，不提交生成产物。`verify` 用于本原型的自动检查，不替代人工视觉审查或原生客户端验收。
