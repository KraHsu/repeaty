# 卡组与资料分享

Repeaty 的分享围绕可继续学习的卡组和资料。当前已有单份资料导出和卡片文件导入；尚无从 Repeaty 导出指定卡组或选中一组资料、连同附件和关联关系一起分享的入口。

## 分享单份资料

在“学习材料”打开资料，选择“导出原文”，可以保存当前正文的 UTF-8 `.md` 或 `.txt` 文件。接收者可以通过“导入材料”将文件加入自己的学习库，开始阅读或制卡。

PDF、EPUB、HTML、图片等已保留原始文件的材料，还可以通过阅读器的“导出原件”取回原始字节；阅读器插件不可用时也保留原件导出。接收者需要对应格式的导入器和阅读器。桌面使用系统保存对话框，无后端网页版使用浏览器下载；这些导出不需要发布网站或配置服务器。

单份文件导出的边界：

- 原文导出只包含正文，不额外打包图片、音频、材料属性、批注、文件夹或虚拟集合。
- 原件导出只保存该原始文件。EPUB 等文件自身已有的资源原样保留；HTML 的配套资源和其他独立附件不会自动组成一个包。
- 关联卡片、出处关系、阅读位置、调度及评分记录不随单份文件导出。
- 正文中的 Wiki 链接、材料链接或相对附件路径仍是文字引用；只发送正文不能保证接收者拥有对应目标。需要同时提供所引用的文件，并在接收方核对链接和资源。

## 接收卡片文件

在卡组或“全部卡片”页面选择“批量导入”，选定目标卡组后检查预览并确认：

- **CSV / TSV**：导入问答、双向、挖空卡的文字、标签及格式。字段为 `front`、`back`，可选 `type`、`tags`、`format`；不包含附件、来源材料和学习进度。每批最多 5,000 条，文件最大 2 MiB。接收的内容生成新卡片，可跳过同一卡组内的相同内容。
- **Anki `.apkg`**：导入支持的问答、双向、挖空卡及图片、音频。新内容作为新卡开始学习；已导入内容可以比较后更新并保留已有进度。Anki 的复习记录不导入。具体格式边界见[Anki 导入](ANKI.md)。

以上是文件接收能力。目前没有从 Repeaty 导出单个或多个卡组为 CSV、Anki `.apkg` 或专用卡组分享包的功能。

## 备份与分享的区别

“数据与备份”中的 `.repeaty` / JSON 保存整库卡组、材料、附件和个人学习记录，恢复时会替换当前学习库数据。它们不会按指定卡组筛选，也不会重置发送者的调度、阅读进度或评分历史，不适合作为普通卡组分享文件。

`.repeaty-workspace` 完整目录备份还包含草稿、已安装插件包、设置和插件私有文件等，用于恢复工作目录。设备凭据和插件信任不包含在内，但这不代表备份内容已经适合对外分享。完整内容范围见[工作目录备份](WORKSPACE_BACKUP.md)。

## “分享摘录”的含义

桌面版“通过 MCP 制卡”中的“分享这段摘录”，是临时授权已连接的 AI 客户端读取当前选区并提交待确认的卡片草稿，不会生成用户间分享链接或资料包。该能力在无后端网页版不可用。见[MCP 制卡](MCP.md#从摘录生成草稿)。
