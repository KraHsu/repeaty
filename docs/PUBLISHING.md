# 发布学习材料

在「插件」中按需安装 **静态发布**、**WordPress 发布** 或 **Discourse 发布**。安装后侧栏出现对应页面。静态站的主题与 Cloudflare 配置位于「设置 → 工具 → 发布」，WordPress 和 Discourse 连接位于「设置 → 连接」的对应分类。三个插件都独立加载；停用或卸载不会删除学习材料、发布关联或远端内容。

## 静态站点

1. 在设置中填写站点名称、说明和公开地址，选择需要公开的自定义字段；可编辑页面、归档、CSS 和 JavaScript 模板。
2. 在「静态发布」中明确勾选材料并生成预览。检查正文、图片、归档、分类、标签及搜索；草稿和私有材料会阻止生成。
3. 导出 ZIP 后，可把解压后的完整文件集放到静态托管服务。站点包含 RSS 与站点地图。重新生成时保留文章地址和首次发布时间，取消选择会从下一版站点移除文章。
4. 桌面版也可在设置中连接 Cloudflare Pages，创建目标项目，再从发布页确认部署。完整文件集替换所选分支的站点；清空选择可生成不含文章的站点。删除整个 Cloudflare 项目是设置里的独立操作，需要再次确认。

主题预览允许站内导航和默认搜索，但不执行用户主题脚本，也不访问外部链接。导出站点保留主题脚本。模板出错或生成失败会保留上次完整站点；重启后可以查看已有预览，导出或发布前需要重新生成并核对当前材料。

网页支持生成、预览和导出 ZIP；使用 Cloudflare 凭据和原生联网需要桌面版。

## WordPress 和 Discourse

在统一设置中填写 HTTPS 网站并连接账号。首次连接用户指定的网站时，Repeaty 会显示完整网站来源供确认。凭据只保存在当前设备，发布关联随工作目录保存。

- WordPress 支持 REST 应用密码，以及启用 XML-RPC 的 WordPress / WordPress.com 站点。连接方式及 Blog ID 取决于网站配置。
- Discourse 使用站点提供的 User API 授权。授权页面生成的加密结果由插件在本地解密，私钥仅保留在本次授权流程中。

从发布页面选择材料，调整文章标题、分类或标签，准备预览后再确认提交。已有发布关联会更新同一篇文章或主题。删除远端文章也是独立的预览和确认操作，不会删除本地学习材料。

这两个连接器不会上传本地图片或附件。含本地资源的正文需要先改用已公开的 HTTPS 地址，或选择静态站点发布。材料之间的链接需要目标已有可核对的公开地址；无法转换的内部链接会明确阻止发布，避免输出内部材料身份。

## 中断、冲突与备份

停止等待不等于撤回远端操作。超时或断网后如果不能确定远端结果，先使用「核对远端状态」，不要重复创建文章。远端在预览后被编辑时会停止更新，要求重新预览；已经发布的内容不会因为学习库撤销或恢复本地备份而自动撤回。

移动完整工作目录后，插件设置、站点产物和发布关联仍在，但新设备需要重新连接账号。卸载插件不会撤下已经公开的站点或文章；需要先执行相应的远端删除操作。

插件包内 README 提供各连接器的具体权限、限制和操作说明。SDK 开发接口见 [插件发布接口](PLUGIN_PUBLISHING.md)。
