# ADR 008：阅读轮次与下一篇

- 状态：已发布，0.18.0
- 日期：2026-10-20
- 范围：静态版、账户版、桌面本地与上游模式

## 问题

材料已经支持位置保存、日期队列与优先级，但连续阅读仍需要手工选下一篇。需要一轮有限的阅读流程，按既有顺序逐篇阅读，保存失败时保留当前材料，不把阅读当作卡片评分。

## 决定

点击「开始一轮阅读」，先保存当前已显示的阅读位置，再按此时的待阅读顺序生成临时列表。列表只保存材料 ID 和不可变快照 ID，以及当前索引，不复制正文。优先级、安排日期、导入时间和 ID 的排序规则沿用 ADR 007，不受当前搜索词和列表分页限制。

本轮顺序固定，每份快照至多出现一次。调整优先级不会重排本轮；新导入或后来到期的材料等下一轮。推进时跳过已删除、快照已替换、已延后或已归档的材料，不向被替换的内容写入旧位置。

「下一篇」先捕获原文或预览位置，调用现有 `useLibrary.saveSourceReading`，成功后再推进。失败保留原篇和索引，显示错误，允许重试。「完成本轮」使用同一保存流程，到末尾显示结束页面；仍然可读的材料不会自动回到本轮。延后和归档继续把位置与安排一起保存，成功后推进本轮；优先级调整停留在原篇。

轮次中收起列表与筛选，工具栏随页面滚动保持可见。「结束本轮」保存当前位置后返回普通材料浏览；若正文未能读取，没有新位置可捕获，可以直接结束，保留已有位置。读过、结束或跳过均不产生 FSRS 评分，也不自动判断掌握。

## 生命周期与保存

轮次仅驻留材料页面，离开页面、刷新、退出应用或切库后结束。每份材料的阅读位置、日期和优先级照常保留；重新开始时根据当前待阅读生成新列表。本轮索引不进入学习库、快照或备份，不提供跨重启续接同一轮的承诺。

界面在等待期间禁止重复推进；提交完成后检查页面是否仍存在、库作用域和轮次身份，迟到响应不能在新页面恢复旧轮次。应用操作继续校验作用域、快照 ID 和修订号。位置保存成功只确认操作所包含的那条待保存位置，较新的滚动仍可由自动保存队列处理。

沿用 Library v9、IndexedDB v12、SQLite v6、HTTP API v7、`.repeaty` v6 和 JSON v9，无学习格式或服务端接口变更。后端仍只处理账户、记录和附件；没有新增调度服务。

## 验证与后续

领域测试覆盖开始顺序、固定顺序、去重、排除新材料、失效快照、延后与归档、空列表和有限结束。应用测试覆盖延迟保存期间切库，拒绝旧操作。

三版本浏览器流程覆盖下一篇、优先级变更、延后、归档、结束、再次开始、退出轮次、重开和完整备份，并比较原笔记、卡片、复习、练习与提交。配额及服务故障验证不推进和重试；迟到响应不能恢复已退出的轮次，正文错误仍能退出。中英文与窄屏检查工具栏可见和页面宽度。Linux 原生流程完全退出重开应用，检查阅读位置、安排及原学习记录。

参考 [Foliole 阅读流程](../READING_REFERENCES.md)，本轮先提供手动轮换。0.19.0 的独立一级摘录见 [ADR 009](009-independent-reading-excerpts.md)；自动阅读间隔、混合队列和嵌套提取仍单独评估。

## 0.23.0 补充：筛选阅读

材料列表支持标题、原文 / 摘录、优先级组合筛选，所有队列的数量以相同条件计算。未设置类型的来源是原文，未设置优先级时按普通处理；已解除出处的摘录继续按摘录处理。匹配不读取正文，分页在完整结果上执行。

保留「开始一轮阅读」读取全部待阅读；新增「阅读筛选结果」只读取当前列表中符合条件的待阅读材料，覆盖全部分页。稍后阅读、归档列表与空结果禁用此入口；全部材料视图仍只纳入已经可读的部分。两种入口均先保存当前位置，失败时保留界面条件，不创建轮次。

筛选轮次保存开始时的筛选值副本和材料快照身份，阅读中收起控制并展示条件。当前篇或后续篇的优先级变动不会将它移出已开始的轮次；快照替换、删除、延后与归档沿用原跳过规则。「再读一轮」用原条件重新匹配当前待阅读，返回列表继续显示原筛选。全量入口清除筛选并回到待阅读。

主动打开摘录时清除筛选并显示全部材料，保存新原文或摘录时清除筛选并回到待阅读，避免目标被原条件隐藏。轮次中的摘录弹窗不改变范围。筛选与轮次只存活于材料页，不写学习库、备份、快照或偏好；离开、重启或切库后恢复默认。

沿用 0.22.0 的 Library v11、IndexedDB v14、SQLite v8、HTTP API v9、`.repeaty` v8 和 JSON v11。验证包含跨页的混合材料、旧记录默认值、脱离原文的摘录、中英窄屏与键盘、保存失败重试、迟到启动响应及原生 WebKit。既有卡片、评分、FSRS 与阅读安排保持原样。
