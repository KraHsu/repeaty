# ADR 002：通过运行中的桌面窗口提供只读 MCP

- 日期：2026-10-19
- 状态：采用
- 范围：桌面本地学习库；三个只读查询

本 ADR 记录 0.12.0 的实现。0.13.0 的选区授权、草稿提交与请求体上限扩展见 [ADR 003](003-mcp-card-drafts.md)。

## 问题

桌面本地库由 WebView IndexedDB 保存，应用当前使用 Vue、Zod 与 ts-fsrs。原生进程中只有上游传输、本地插件凭据与文件导出能力，没有可供 rmcp 直接读取的学习库 SQLite。

独立 stdio 进程不能直接使用当前窗口的 IndexedDB 事务与已加载工作空间。为此迁移存储或调度会扩大本阶段范围，也会引入三个版本的兼容工作。

## 决定

将 MCP 监听放在现有 Tauri 进程内，使用 `rmcp = 3.5.1`（Apache-2.0）与 Streamable HTTP。只在用户开启后绑定 `127.0.0.1:0`，给出随机端口与本次连接的 Bearer 密钥；连接和密钥不持久化。

原生端使用 Tauri IPC Channel 将受限查询交给当前主窗口；窗口通过 `useLibrary.readLearning` 校验本地作用域、就绪和保存状态，再从同一份已提交内存视图生成结果。原生端不打开 WebView 数据文件、不复制学习库、不开放通用 JavaScript、网络或文件调用。

三个查询为待复习问题、学习统计和练习摘要。问题投影沿用现有调度队列；历史投影只用摘要索引，不读取代码或裁判详情。结果明确列出可返回字段，不直接序列化 Note、CardView、Practice 或插件原始数据。分页绑定修订号；投影与回复之间不执行数据写入。

## 生命周期和限制

- 仅主窗口能注册桥接、控制连接和回复查询。每次注册生成新的 attachment ID，旧窗口消息无效。
- 工作空间更新带递增序号和作用域世代，拒绝乱序旧消息；离开后重新打开同名库也会撤销旧连接。
- 临时忙碌会取消待回复查询；窗口重载、endpoint 切换及停止连接会关闭监听、清空待回复记录并撤销密钥。
- HTTP 校验精确 Host、拒绝所有带 Origin 的请求，并验证 Bearer 密钥。协议由 SDK 处理；请求体上限 8 KiB。
- 最多同时等待 8 个窗口查询，4 秒超时；取消、超时和结束都会释放槽位。单个结构化结果上限 4 MiB。
- 第一版没有 stdio 启动器、后台读取、远程 MCP 或上游账户库接入。应用未运行时应连接失败，窗口无响应时返回超时。

## 验证

TypeScript 测试验证额度、暂停、埋藏、双向和挖空问题投影、字段范围、分页修订以及撤销后的统计。浏览器测试通过应用接口读取导入的真实学习库，并比较读取前后的记录。

Rust 测试使用官方 MCP 客户端连接实际的本机 HTTP 监听，完成发现和查询；另验证 `2025-11-25` 初始化、鉴权、Origin / Host、请求体上限、乱序切库、待回复取消、并发上限和超时。

Linux 原生验收通过真实 WebKit 窗口和 IPC Channel，运行外部 HTTP 客户端查询 IndexedDB 的入门卡组，核对结果与读取前后的记录；验证关闭、重新开启、重载及切换上游后旧连接失效。三平台安装包继续由 Desktop CI 构建。

## 代价

每次重新开启需更新客户端配置，且 Repeaty 窗口必须运行。这是首版明确的使用方式；稳定端口、持久授权或 stdio 代理在实际需要时另议。读取与界面共用主线程和已加载数据视图，不宣称具备独立存储服务或后台快照能力。
