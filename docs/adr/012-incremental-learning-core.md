# ADR 012：渐进学习核心流程

- 状态：已实现，等待 0.24.0 合并
- 日期：2026-10-20
- 范围：静态版、账户版、桌面本地与上游模式

## 问题

现有材料支持独立摘录、阅读日期与轮次，但大量材料只能逐篇安排，摘录不能继续缩小，安排失误也没有直接撤销。阅读和卡片复习的入口尚未连起来。

本阶段一次完成材料批量整理、多级出处、最近一次安排撤销与日常入口，集中在 PR #31。PDF / 网页采集、Obsidian 和自适应算法仍为长期工作。

## 批量安排与撤销

选择本页或当前筛选的所有分页，提交前固定来源 ID、正文 ID、原安排和工作空间。纯函数先验证所有目标，再生成优先级、日期、归档或恢复的整批变化；单次保存提交全部记录与当前目标的可用阅读位置。失败保留原库、选择与表单，不部分生效。

批量操作不代替阅读确认，不批量推进递增间隔。设置优先级保留日期，手动日期与恢复会将选中材料移为活动状态。操作前沿用自动快照。

工作空间仅保留最近一次有效安排的 `ReadingUndo`，记录变化目标的正文身份与安排前后值。单篇与批量共用一份撤销；无变化的操作不替换它。撤销只恢复日期、活动 / 归档状态、优先级和递增间隔，保留之后的标题、URL、阅读位置、笔记和 FSRS 评分。

所有目标必须仍匹配操作后的正文与安排，否则整次拒绝。账户版另外受服务修订检查保护。撤销保存失败时保留记录，允许重试。刷新、退出、切库与恢复备份后清除；不增加持久事件表。跨重启恢复使用已有快照，恢复范围是整个库。

阅读轮次记录最近一次安排前后的轮次身份。若仍停在该操作推进的位置，撤销同时回到原篇；用户已经继续前进时只恢复安排，不强制跳转。

## 多级摘录

沿用 `Source.kind`、`Source.origin` 和独立正文 Blob。出处始终指向直接父材料，不扁平化成根原文。每级独立保存位置、日期、间隔与优先级，不继承父级安排。

前端和 Rust 分别检查不存在缺失父级、环和超过 32 条出处边的链。正文校验仍按直接父级分组读取，UTF-16 范围必须与子正文完全相同；不在启动时载入全部正文。创建第 33 层或导入非法层级会整批失败。

阅读器列出出处路径。回看卡片时，逐级将选区偏移加上当前摘录在父材料中的起点，定位每级实际选区；重复文本不靠全文搜索。每次只读取当前显示的材料，切换时取消旧请求。

删除中间材料只解除直接子材料的出处，孙级仍指向保留的子材料。其余正文、位置、安排与卡片进度保留；引用被删材料的笔记解除关联但保留内容与评分。完整备份和快照恢复多级关系。

## 日常入口

首页从现有队列统计当天可读的原文与摘录，开始阅读时等待阅读器恢复位置后启动有限轮次。结束页进入正常卡片复习，继续使用原 FSRS 队列与卡组额度；不引入混合队列或自动评分。
