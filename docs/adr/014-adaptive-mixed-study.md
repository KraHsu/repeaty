# ADR 014：自适应阅读与混合学习

- 状态：已实现，本地整体验证通过；待 PR 合并
- 范围：静态版、账户版、桌面本地与上游模式

## 自适应阅读

保留固定递增方式。每篇原文与摘录可以在「读过，安排下次」中选择自适应，根据「需要再读 / 基本理解 / 已经熟悉」与实际经过的日历天数预览下次日期，确认后才保存；打开、滚动和普通下一篇不计为阅读反馈。

Source 增加可选 `adaptiveReading`：上次间隔、增长系数、上次阅读日期、确认次数与反馈。它表示阅读理解反馈，不是 FSRS 记忆状态。首次以原固定间隔或 1 天为基数，系数为 2；未设置过间隔的材料首次三种反馈分别为 1、2、3 天。

需要再读时，间隔减半、系数减 0.2；基本理解使用经过天数乘以系数，熟悉时系数加 0.15 并额外乘 1.3。经过天数限制在上次间隔的一半与两倍之间，系数为 1.3–3，最终间隔四舍五入并限制在 1–365 天。提前阅读时，新间隔不超过上次间隔；严重逾期也不会无界扩大。日期使用本机日历，天数差按日期计算，避免夏令时带来的小时差。

预览包含预期确认次数，应用根据最新材料重新计算；旧预览、过期日期与归档材料拒绝提交。位置、反馈和日期在同一事务保存。自适应与固定方式在确认时切换，重置移除两者的间隔状态，保留已安排日期。手动日期、优先级、归档与恢复保留已有间隔状态。阅读撤销一并恢复反馈与间隔，保留后续卡片评分。

## 混合学习

从学习概览开始，默认每 3 次卡片评分穿插 1 篇材料，可选 1–10。卡片始终从现有实时 FSRS 队列选择，保留每日额度、插件可用性、暂停、暂缓及到期重学规则，不提前显示未来卡片。一类用尽时继续另一类。

材料在开始时固定当天待阅读的身份、正文与优先级顺序，每篇本轮至多处理一次；之后新导入的材料留到下一轮。删除、替换、归档或延后的目标跳过。完成阅读先保存位置，确认阅读安排时同样先保存再推进；失败保留当前项和表单。阅读时到期的卡片在下一次切换时进入，不打断当前材料。

混合界面复用原阅读器、笔记编辑器、插件题型与评分操作。保存成功才累计完成数量；阅读不产生复习评分。异步回调绑定当前项身份，旧组件、旧轮次和旧库的响应不能推进新轮次。结束与撤销前保存当前阅读位置，失败可重试。撤销评分保留阅读安排，撤销最近阅读安排保留已提交的卡片评分。

轮次与比例只保留在当前界面，退出、刷新、恢复或切库后重新开始。日期、反馈、位置、卡片进度与记录正常持久保存；不增加自动跨端同步或后台学习服务。

## 验证

本地通过 291 项单元测试（另 1 项跳过）、147 项浏览器测试（静态 62、桌面 48、账户 37）和 49 项 Rust 测试。覆盖旧库迁移、反馈与日期、每日额度、插件可用性、分别撤销、失败重试、迟到响应、备份、长文本和 128 MiB 媒体。Linux 真实 WebKit / Rust IPC 完成反馈、混合轮次、两类撤销与实际退出重开；无图形会话的 MCP stdio smoke 通过。PR 中继续检查三平台构建，Windows / macOS 的人工 GUI 验证留在发布清单中。
