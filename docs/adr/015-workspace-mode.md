# ADR 015：桌面工作目录

- 日期：2026-10-26。
- 状态：用户确认收敛为桌面主要产品；正式学习存储已接入功能分支，尚未发布。
- 产品基线：0.27.0；正式目录格式：3。
- 当前范围与限制：[工作目录](../WORKSPACE_MODE.md)。

## 决策

1. 一个学习库是一个自包含目录，由桌面客户端直接打开。桌面不再区分 IndexedDB 本地库与上游账号库。
2. 笔记与材料使用 Markdown；SQLite 保存学习状态、身份映射、结构化记录、检查点和辅助草稿；附件存为不可变文件。
3. 外部编辑通过检查、校验与明确接受进入当前学习状态。保存时协调数据库事务和文件发布，保留实际被替换的原文件；不把 SQLite 事务当作跨文件原子操作。
4. 目录身份独立于路径。设备上的最近目录、登录凭据与 MCP 授权不属于学习目录；目录内数据不能自动授予代码执行权限。
5. 用户明确项目暂无其他使用者，因此直接切换新格式，不开发旧 IndexedDB、账户服务或 M0 实验格式的过渡、迁移与双写。旧数据不自动删除。
6. 保留共享 Vue 界面、领域模型、ts-fsrs 和现有学习功能。Rust 成为桌面内部存储，不为此另建网络服务或账户系统。
7. 在线入口在无后端的前提下尽可能展示可用能力，复用共享逻辑，按需要使用浏览器接口、针对性适配或 WASM。已接入只读打开用户选择的本地工作目录，试用操作与原目录及原网页学习库隔离；不以删减网页功能为目标。跨设备同步另行设计，复制活跃 SQLite 文件不等同于同步。私有 IAM 部署不在本轮修改范围内。

## 实现与后续

正式存储位于 `crates/workspace-store/src/{library,records,sessions}.rs`，Tauri 只暴露有会话约束的目录读写命令。前端 `src/desktop/repository.ts` 适配现有学习接口；评分发送增量记录，不扫描文件。

原 M0 的 codec、变更分类、不可变版本与原子文件操作继续复用。`prototype` / `preview` 的独立协议及测试保留为实验资料，不作为正式格式兼容入口。此前规划的旧库迁移阶段取消。

当前支持笔记的外部新建、修改、改名、移除及恢复。SQLite 在同一事务中保留退役卡片与完整练习记录；相同变体重新出现时复用原身份和调度。材料版本接受、相对路径附件和自动检测已接入。在线版通过已有 `sql.js` WASM 与 Worker 读取目录快照，评分、编辑与阅读继续复用共享核心；不调用原生打开或恢复逻辑。同步仍待后续，未接入的能力不标为完成。
